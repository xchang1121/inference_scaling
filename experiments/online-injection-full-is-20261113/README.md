# 从起点接管的 IS 在线知识注入：实现验证

本次修正已接入独立入口 `scripts/benchmark_online_is.py`。固定输入只有原问题与 `<think>` 开头；
原有 IS 从第一个思考 token 开始，候选各自检索并注入事实，最终答案沿选中候选的完整上下文续写。

未修改原有 Block-Metropolized IS、SC 评分或参数：M=3、K=2、block=512、SC 温度 0.25，
保留思考 8192、搜索生成预算 65536、答案预算 16384。17 个冻结文件的 SHA-256 全部一致。
检索在候选已生成 128 / 512 token 时触发，查询为问题加该候选最近 256 token，每次注入 256 输入 token。
不额外生成检索规划或临时答案；注入文本不计入 IS 分块、生成预算或 SC 评分。

本地 39 项测试通过；原 Qwen3.8-27B / Ascend 原生验证完成 2 道 TRAIN 题 × 4 组，共 8 次运行。离线审计通过 1534 项检查。
审计重放了原 IS 的所有候选请求、评分、选择、完整候选池预算，并核对每次注入的分支归属、续写上下文、生成计数和最终答案。
篡改分支查询、采样偏移、选中上下文或 IS 选择的测试均能检出。自身验证容器已停止。

两道题的实际选中路径位置、注入长度及源窗口见 [selected-paths.json](selected-paths.json)。

## 离线重放

在安装了项目基础依赖的 Python 3.12+ 环境中运行（目标目录需不存在）：

```sh
python replay.py --destination /path/to/new/replay-directory
```

脚本验证包内逐文件哈希，展开冻结生成源码和原生记录，再重放审计，并要求审计结果逐字节一致。
原生重新运行还需要既有模型、vLLM/Ascend 环境，以及 `inputs/corpus-reference.json` 指向的已冻结语料。
`tools/` 保存本次部署脚本作为来源记录，其路径依赖原工作区；原生执行参数与启动脚本另保存在 raw 归档内。
旧 IRCoT/ThinkRetrieve 结果保留其原接法，不能视作本版全程在线 IS 的结果。
