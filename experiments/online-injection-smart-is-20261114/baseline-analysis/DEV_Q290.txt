ANSWER
## Answer

**No.** Running a monitored JBoss Application Server with ITCAM for J2EE as a Windows service is **not supported**.

### Technical Reason

When you configure JBoss to run as a Windows service, the process requires downloading the JBoss native connectors and modifying the `service.bat` file. ITCAM for J2EE's agent/DC also makes modifications to those same native connector files during installation/configuration. Because of this conflict, the Windows service configuration is incompatible with the ITCAM for J2EE agent/DC, and IBM explicitly states this combination is **currently not supported**.

An additional limitation is that there is **no option to specify the Windows Service name** during the JBoss server configuration steps in the ITCAM setup.

### Version Note

If you are using **JBoss AS 7.1** or **JBoss EAP 6.1.0 / 6.2.0 / 6.3.0**, you must first apply the latest ITCAM patch (referenced in the IBM developer answers knowledge base) before attempting any service-related configuration, though even then the Windows service + ITCAM combination remains unsupported.
