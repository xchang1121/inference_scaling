# 自回归语言模型与投机解码

## 1. 下一 token 预测

### 1.1 文本与下一项概率

语言模型处理的基本单位称为 token。一个 token 可以表示一个字、词的一部分、标点或特殊符号。
分词器把文本转换为一串整数，每个整数对应词表中的一项。记词表为 $\mathcal V$，大小为 $V$。

以一句简化为四个 token 的文本为例：

```math
[\text{I},\text{love},\text{New},\text{York}].
```

给定前缀“I love”，模型为下一项提供一张概率表，例如 New 的概率为 0.6、you 为 0.3，
其余项合计 0.1。按这张表抽样，得到 New 的概率就是 0.6。

用 $x_1,\ldots,x_T$ 表示整段文本，并在序列前附起始符 $x_0$。
$x_{<t}$ 表示 $x_0,\ldots,x_{t-1}$。模型的输出写成

```math
p_\theta(x_t=v\mid x_{<t}).
```

竖线右侧是已经给定的前缀，左侧是被预测的 token；$\theta$ 汇总模型参数。
固定一个前缀，对词表中的全部 $v$ 求和，概率之和等于 1。

模型用向量表示文本。向量是一组按顺序排列的数；输出层把它转换为每个词表项的分数，称为 logit。
设分数为 $\ell_1,\ldots,\ell_V$，softmax 将它们变成概率：

```math
p_\theta(v\mid x_{<t})
=\frac{\exp(\ell_v)}{\sum_{u=1}^{V}\exp(\ell_u)}.
```

$\exp$ 是指数函数，把实数变为正数；$\sum$ 表示求和。
分母将所有正数归一化，使总和为 1。较高的 logit 对应较大的概率。

### 1.2 训练中的并行预测

下一 token 预测简称 NTP，英文为 next-token prediction。
训练数据提供完整句子，各位置的输入与监督关系为：

| 输入位置 | 该位置可以读取的文本 | 训练要求它预测的下一项 |
|---|---|---|
| I | I | love |
| love | I love | New |
| New | I love New | York |

一次前向计算是输入经过各层网络、得到输出 logits 的过程。
表中三个位置的输入同时给定，模型的一次前向可以同时算出三张概率表。
因果注意力限定每个位置读取自身及左侧输入，使各行保持表中的前缀条件。
这种用真实前缀提供输入的训练方式称为 teacher forcing。

训练损失为

```math
\mathcal L_{\mathrm{NTP}}(\theta)
=-\frac1T\sum_{t=1}^{T}\log p_\theta(x_t\mid x_{<t}).
```

$\log$ 是自然对数。真实 token 的概率从 0.1 提高到 0.8 时，单项损失从约 2.303 降到 0.223。
最小化这个平均损失，就会提高训练文本中真实下一项的概率。

参数的导数描述参数微小变化时损失的变化率。把所有参数的导数组成向量，得到梯度
$\nabla_\theta\mathcal L$。梯度下降用
$\theta\leftarrow\theta-\eta\nabla_\theta\mathcal L$ 调整参数，
其中学习率 $\eta>0$ 控制每次调整的幅度。

### 1.3 生成中的串行依赖

生成时，输入可能只有“I love”。后续计算沿抽样结果展开：

```math
\begin{aligned}
x_3&\sim p_\theta(\cdot\mid\text{I love}),\\
x_3=\text{New}
\quad&\Longrightarrow\quad
x_4\sim p_\theta(\cdot\mid\text{I love New}).
\end{aligned}
```

$\sim$ 表示按右侧分布抽样，$\cdot$ 表示整张词表概率表。
第一张表中抽到 New 后，New 成为第二张表的输入条件。
这构成了逐 token 的数据依赖。

自回归的英文为 autoregressive，简称 AR。
整段文本的概率由每一步的条件概率相乘得到：

```math
p_\theta(x_{1:T}\mid x_0)
=\prod_{t=1}^{T}p_\theta(x_t\mid x_{<t}).
```

$\prod$ 表示连乘。例如三项序列的概率为
$p(x_1)\,p(x_2\mid x_1)\,p(x_3\mid x_1,x_2)$，这里省略了共同的起始符条件。
NTP 训练把各个真实前缀同时提供给模型；AR 生成的前缀随着每次抽样逐项形成。

推理常使用温度、top-k 和 top-p 调整抽样分布。
正温度 $\tau$ 将 logits 替换为 $\ell/\tau$，较小温度使概率集中。
top-k 保留概率最高的 $k$ 项；top-p 保留降序累计概率达到阈值的最短前缀，包含跨过阈值的那一项。
保留项经过重新归一化，形成实际抽样分布。
贪心解码选择最大 logit，可写成在该项上概率为 1 的特殊分布。

以下用 $p$ 表示实际使用的目标分布，包含约定的温度和截断设置。
AR 对照与投机验证使用同一套设置。

## 2. 候选序列与并行评分

### 2.1 已知序列的条件概率

设已有文本为 $s=\text{“I love”}$，候选续写为

```math
(y_1,y_2,y_3)=(\text{New},\text{York},\text{City}).
```

把 $[s,y_1,y_2,y_3]$ 作为已知输入，一次因果前向可以同时得到

```math
\begin{aligned}
p_1&=p(\cdot\mid s),\\
p_2&=p(\cdot\mid s,\text{New}),\\
p_3&=p(\cdot\mid s,\text{New},\text{York}),\\
p_4&=p(\cdot\mid s,\text{New},\text{York},\text{City}).
\end{aligned}
```

其中 $p_1,p_2,p_3$ 分别为三枚候选提供验证概率，$p_4$ 提供它们之后的下一项概率。
候选是否符合目标分布，影响随后保留哪些 token；这些概率表的计算条件已经由候选文本给定。

AR 生成逐项形成输入，候选评分使用整条已知路径。
这与训练时用完整句子并行计算各行预测具有相同的输入条件。

### 2.2 目标分布与起草分布

投机解码用起草分布 $q$ 提供候选，用目标分布 $p$ 校正候选的输出概率。
起草器也称 drafter，目标模型在验证阶段称为 verifier。

经典方法使用一个较小的 AR 模型作为起草器：

```math
\begin{aligned}
y_1&\sim q_1(\cdot\mid s),\\
y_2&\sim q_2(\cdot\mid s,y_1),\\
y_3&\sim q_3(\cdot\mid s,y_1,y_2).
\end{aligned}
```

小模型承担三个串行起草步骤，大模型用一次前向为候选路径评分。
整条候选序列的概率称为联合概率，其起草分布为

```math
q(y_{1:m}\mid s)
=\prod_{i=1}^{m}q_i(y_i\mid s,y_{<i}).
```

这里 $y_{<i}$ 表示当前候选之前的全部候选。
起草器的规模决定每个步骤的成本，$q$ 与 $p$ 的接近程度影响候选的接受率。
其他起草结构可以同时计算多个位置的概率表。[投机解码原论文](https://proceedings.mlr.press/v202/leviathan23a.html)

### 2.3 缓存与块计算

嵌入层、注意力层和前馈层等主体网络合称模型骨干。
注意力用“键”描述历史位置的匹配信息，用“值”提供被汇总的内容。
KV cache 保存这些历史键和值；提示文本的首次处理称为 prefill。
后续生成读取历史 KV，并计算新位置。注意力的矩阵公式见附录 C。

在单请求、短查询的解码中，读取模型权重与历史 KV 往往占据较大开销。
一块已知输入可以在一次前向中共同使用这些权重和历史数据，分摊部分读取与启动成本。
块长增加也会增加计算量和缓存访问量，实际耗时由模型、硬件与执行实现共同决定。

## 3. 投机解码的概率校正

### 3.1 概率质量的数值例子

设词表只有 A、B、C 三项，目标与起草分布分别为

```math
p=(0.5,0.3,0.2),\qquad q=(0.4,0.4,0.2).
```

起草器分给 B 的概率比目标多 0.1，分给 A 的概率少 0.1。
候选为 B 时保留其中的 $0.3/0.4=75\%$；候选为 A 或 C 时全部保留。
这使直接接受的概率质量成为：

| 概率质量 | A | B | C |
|---|---:|---:|---:|
| 目标 $p$ | 0.5 | 0.3 | 0.2 |
| 起草 $q$ | 0.4 | 0.4 | 0.2 |
| 直接接受 | 0.4 | $0.4\times0.75=0.3$ | 0.2 |
| 拒绝后补充 | 0.1 | 0 | 0 |
| 最终输出 | 0.5 | 0.3 | 0.2 |

拒绝发生的总概率为 $0.4\times0.25=0.1$。每次拒绝都改为输出 A，
恰好补齐 A 缺少的 0.1。最终输出的三项概率因此等于 $p$。

### 3.2 接受、拒绝与残差分布

上述规则可以推广到任意词表。候选 $Y$ 按 $q$ 抽取，以概率

```math
a(Y)=\min\left(1,\frac{p(Y)}{q(Y)}\right)
```

接受。具体实现从 $[0,1]$ 均匀抽取 $U$，满足 $U<a(Y)$ 时保留候选。
直接接受某项 $v$ 的概率为“抽到它的概率”乘“接受它的概率”：

```math
q(v)a(v)
=q(v)\min\left(1,\frac{p(v)}{q(v)}\right)
=\min(p(v),q(v)).
```

目标中剩余的质量为
$p(v)-\min(p(v),q(v))=[p(v)-q(v)]_+$，
其中 $[x]_+=\max(x,0)$。
拒绝分支按这部分质量归一化后的残差分布抽样：

```math
r(v)=\frac{[p(v)-q(v)]_+}{Z},
\qquad Z=\sum_u[p(u)-q(u)]_+.
```

由于 $p,q$ 的概率总和均为 1，总拒绝概率恰好等于 $Z$：

```math
\sum_v\bigl(q(v)-\min(p(v),q(v))\bigr)
=\sum_v\bigl(p(v)-\min(p(v),q(v))\bigr)
=Z.
```

用 $\Pr$ 表示事件的概率，将接受与拒绝两个分支相加，得到

```math
\begin{aligned}
\Pr(\text{输出 }v)
&=\min(p(v),q(v))+Zr(v)\\
&=\min(p(v),q(v))+[p(v)-q(v)]_+\\
&=p(v).
\end{aligned}
```

$q(v)=0$ 的项由残差分支承接目标质量。
$p=q$ 时，全部候选都被接受，$Z=0$。

这就是无损投机解码中的概率保持：输出遵循目标分布 $p$，起草分布的质量决定候选保留的机会。
随机数的消耗顺序会影响单次运行的具体样本。
精确算术下，贪心目标的验证简化为与目标最大项比较；浮点舍入的影响见第 8.2 节。

### 3.3 接受率与总变差距离

两张概率表的总变差距离，简称 TV，是

```math
D_{\mathrm{TV}}(p,q)=\frac12\sum_v|p(v)-q(v)|.
```

它表示将一张概率表变成另一张表时，需要搬动的概率质量。
第 3.1 节的例子把 0.1 的质量从 B 搬给 A，故 TV 为 0.1。

利用 $\min(a,b)=(a+b-|a-b|)/2$，平均接受率为

```math
\Pr(\text{接受})
=\sum_v\min(p(v),q(v))
=1-D_{\mathrm{TV}}(p,q).
```

例子中的接受率就是 0.9。
在同一实际前缀上减小 TV，会提高该位置的平均接受率。
这为起草器的分布训练提供了直接依据。

### 3.4 连续前缀与每轮输出

多个候选按顺序应用接受规则。本轮保留连续接受的前缀；
首次拒绝时，输出残差分布中的一枚替代 token，并结束本轮。

例如，候选为 New / York / City。New 被接受，York 被替换为 Jersey 时，
下一项的目标分布变为 $p(\cdot\mid s,\text{New},\text{Jersey})$。
本轮已经算出的第三行则是 $p(\cdot\mid s,\text{New},\text{York})$。
后续计算从更新后的前缀“I love New Jersey”继续。

全部候选接受时，末行 $p_{m+1}$ 提供一枚额外 token。
若 $A$ 表示连续接受的候选数，输出预算充足、该轮继续生成时，

```math
L_{\mathrm{经典}}=1+A,\qquad 0\le A\le m.
```

固定的一项来自拒绝后的替代 token，或全部接受后的额外 token。
对每个实际提交的前缀应用第 3.2 节的等式，条件概率乘法法则给出整段输出的目标 AR 分布。

## 4. NTP、MTP 与起草结构

### 4.1 训练目标、候选与验证

NTP 训练得到的模型定义目标分布 $p$。
MTP、独立小模型和扩散起草等结构提供候选分布 $q$。
投机解码将候选与目标验证结合，最终输出遵循 $p$。

多 token 预测简称 MTP。一类结构在同一个骨干表示 $h(s)$ 上连接多个输出头，
每个头把该表示转换为一个未来位置的词表分数。以线性头为例：

```math
q_j(\cdot\mid s)=\operatorname{softmax}(W_jh(s)),
\qquad j=1,\ldots,m.
```

$W_j$ 是第 $j$ 个头的参数矩阵，矩阵乘法对 $h(s)$ 的各项作加权求和，$j$ 对应预测距离。
在位置 $t$ 上，第一个头预测 $x_{t+1}$，第二个头预测 $x_{t+2}$。
相应的训练损失为

```math
\mathcal L_{\mathrm{MTP}}
=-\sum_t\sum_{j=1}^{m}\log q_j(x_{t+j}\mid x_{\le t}).
```

多头分别学习各个未来位置的真实 token。
推理中，这些头的输出可以作为候选，由 NTP 目标模型验证。
[多 token 预测论文](https://arxiv.org/abs/2404.19737)

### 4.2 单位置概率与序列概率

真实 AR 分布对两枚 token 的联合概率为

```math
p(y_1,y_2\mid s)
=p(y_1\mid s)\,p(y_2\mid s,y_1).
```

简单并行多头采用独立抽样时，联合概率为

```math
q(y_1,y_2\mid s)
=q_1(y_1\mid s)\,q_2(y_2\mid s).
```

第二个式子中的 $q_2$ 由同一个前缀 $s$ 算出，第一式的第二项以实际抽中的 $y_1$ 为条件。

设一个简化的目标分布只包含两种续写：“喝／茶”和“吃／饭”，各占一半。
两个位置各自的概率表都是均分：
第一项在“喝／吃”之间均分，第二项在“茶／饭”之间均分。
按这两张表独立抽样，会得到

```math
q(\text{喝,茶})=q(\text{喝,饭})
=q(\text{吃,茶})=q(\text{吃,饭})=\frac14.
```

各位置的概率表都与目标的单位置统计相同，联合分布却给两个交叉组合分配了一半质量。
AR 的第二项则满足
$p(\text{茶}\mid s,\text{喝})=1$、$p(\text{饭}\mid s,\text{吃})=1$。
前一枚实际 token 提供了选择对应续写的信息。

MTP 的架构还包括串联模块形式。
例如 DeepSeek-V3 在各预测深度融合前一深度表示与对应 token 嵌入，保留深度间的条件依赖；
这些模块同时支持辅助训练与投机起草。[DeepSeek-V3 第 2.2 节](https://arxiv.org/html/2412.19437v2#S2.SS2)

### 4.3 各类起草器

| 方法 | 起草参数和输入 | 候选之间的计算关系 |
|---|---|---|
| [独立小模型](https://proceedings.mlr.press/v202/leviathan23a.html) | 另一套较小的语言模型，读取文本前缀 | 小模型逐项生成，后项读取实际前项 |
| [Medusa](https://arxiv.org/abs/2401.10774) | 目标骨干上的多个预测头 | 多个头并行提出未来位置的候选，配合树验证 |

| [层跳跃式自投机](https://arxiv.org/abs/2309.08168) | 起草使用目标模型的部分层，验证使用完整模型 | 部分层组成的起草路径逐项生成 |

| [DSpark](https://arxiv.org/abs/2607.05147) | 并行起草骨干，加轻量串行模块与置信度预测 | 在并行预测上加入实际候选前缀的条件修正 |

EAGLE-3 融合多层目标特征并直接预测 token。Medusa 的版本包括冻结骨干和联合训练两类。
各架构配合的具体验证规则决定最终采样分布，第 3 节给出了概率保持的接受与残差规则。

DFlash 使用自己的轻量骨干，块内表示可以双向交互。
第 5 节的起草与验证共享完整骨干，沿用因果注意力和 NTP 的位置偏移。
共享表示的多头起草主要增加头部计算；共享骨干的扩散起草在各噪声位置运行完整层计算。
它们在起草耗时、参数存储与候选依赖上形成了不同的取舍。

## 5. 共享骨干的分块扩散起草

### 5.1 噪声位置与下一项预测

同一个模型承担两种计算：原骨干提供目标分布，原骨干加扩散 LoRA 提供起草分布。
LoRA 是附加在骨干线性层上的低秩参数分支，可以按输入位置开启或关闭。

设当前文本为 $s$，末尾 token 为 $c$。
取块长 $b=4$，在 $c$ 后附上三个随机 token：

```math
[c,z_1,z_2,z_3].
```

这些随机 token 称为噪声，用来填充起草位置。
四个输入同时给定，因果模型可以在一次前向中算出四个位置的表示。
本节把新增的首枚 token 编号为 $y_0$，称为根 token；其余为 $y_1,y_2,y_3$：

| 输入位置 | 可见内容 | 输出概率表 | 抽取的 token | LoRA |
|---|---|---|---|---|
| $c$ | 干净前缀 $s$ | $p(\cdot\mid s)$ | $y_0$ | 关闭 |
| $z_1$ | $s,z_1$ | $q_1(\cdot\mid s,z_1)$ | $y_1$ | 开启 |
| $z_2$ | $s,z_1,z_2$ | $q_2(\cdot\mid s,z_1,z_2)$ | $y_2$ | 开启 |
| $z_3$ | $s,z_1,z_2,z_3$ | $q_3(\cdot\mid s,z_1,z_2,z_3)$ | $y_3$ | 开启 |

表中每个输入位置仍然预测下一项。$c$ 预测新增的 $y_0$，$z_1$ 所在位置预测 $y_1$。
位置偏移与普通 NTP 完全相同。共享骨干、配对蒸馏及一步起草的来源见文末参考文献 [1]。

干净输入位置 $c$ 关闭 LoRA，因果注意力使它读取的内容全部来自干净历史。
所以第一张概率表就是基座在 $s$ 上的目标分布，$y_0$ 直接按 $p$ 抽取。
其余位置的表由噪声前缀算出，各表分别用于抽取一枚候选。

例如 $q_2$ 的计算输入是 $s,z_1,z_2$，
对应验证分布的输入则是 $s,y_0,y_1$。
给定噪声，线性起草的后续候选独立抽样：

```math
Q(y_{1:3}\mid s,y_0,z)
=\prod_{i=1}^{3}q_i(y_i\mid s,z_{1:i}).
```

多个噪声位置都经过完整骨干，每个位置得到自己的表示。
相比第 4.1 节在同一个表示上增加多个头，这里增加的是一整块输入位置的计算。

### 5.2 条件低秩分支

记基座参数为 $\theta$，新增低秩参数的集合为 $\phi$。
$\theta$ 定义目标分布，$\theta$ 与 $\phi$ 共同产生带噪输入上的起草分布。

原线性层为 $Wh$。矩阵乘向量表示对输入各项作加权求和；
低秩分支用两个较小矩阵表示附加变换：

```math
f(h,m)=Wh+m\frac{\alpha}{r_\Delta}B_\Delta A_\Delta h,
\quad
A_\Delta\in\mathbb R^{r_\Delta\times d_{\mathrm{in}}},
\quad
B_\Delta\in\mathbb R^{d_{\mathrm{out}}\times r_\Delta}.
```

$d_{\mathrm{in}},d_{\mathrm{out}}$ 是输入、输出向量的长度，
$\mathbb R^{a\times b}$ 表示 $a$ 行、$b$ 列的实数矩阵。
$A_\Delta$ 把输入映射到宽度为 $r_\Delta$ 的中间向量，$B_\Delta$ 把它映射回输出空间。
这个中间宽度限制了附加矩阵的秩，即独立变换方向的数量。
$\alpha/r_\Delta$ 是缩放系数，$m\in\{0,1\}$ 是当前 token 的开关。

新增参数量为 $r_\Delta(d_{\mathrm{in}}+d_{\mathrm{out}})$，
原矩阵的参数量为 $d_{\mathrm{in}}d_{\mathrm{out}}$。
适配器通常用随机的 $A_\Delta$ 和全零的 $B_\Delta$ 初始化，初始附加量为零。
[LoRA 论文](https://arxiv.org/abs/2106.09685)

本项目在注意力的 Q、K、V、输出投影，以及前馈层的三种投影上实现该分支。
蒸馏期间固定 $\theta$、训练 $\phi$。
当前本机实验直接加载已发布的 $\phi$，将它与基座共同冻结。

### 5.3 离散噪声与配对蒸馏

普通骨干把每个输入 token 都作为文本内容处理。例如在
“The capital of France is 香蕉”后，模型给出的分布以整段文字为条件。
带噪起草通过 LoRA 和专门的训练，把随机占位 token 对应的输出拟合到干净文本上的教师预测。

离散扩散用随机替换构造这种训练输入。
设原 token 为 $x$，噪声概率表为 $\pi$，时刻 $t$ 的保留率为 $a_t$：

```math
\Pr(z_t=v\mid x)
=a_t\mathbf1[v=x]+(1-a_t)\pi_v,
\qquad a_0=1,\quad a_1=0.
```

$\mathbf1[\cdot]$ 在条件成立时取 1，其余取 0。
时刻 0 保留干净 token；时刻 1 完全从 $\pi$ 抽样。
中间时刻以概率 $a_t$ 保留原值，以概率 $1-a_t$ 从 $\pi$ 重抽。
这里采用均匀替换，本机公开权重的起草噪声范围为整数 $[1,64256)$。

一步起草将完全带噪的块直接映射为干净 token 的预测概率。
完整噪声到干净端点的 $\Psi$ 转移等于模型输出概率，推导见附录 A。

蒸馏用教师的概率表监督学生。
例如训练文本在前缀 $s$ 后接 $x_1,x_2,x_3,x_4$，
目标路径与带噪路径提供下列成对预测：

| 预测位置 | 教师 $P_i$ | 学生 $Q_i$ |
|---|---|---|
| 第二枚新 token $x_2$ | $p_\theta(\cdot\mid s,x_1)$ | $q_{\theta,\phi}(\cdot\mid s,z_1)$ |
| 第三枚新 token $x_3$ | $p_\theta(\cdot\mid s,x_1,x_2)$ | $q_{\theta,\phi}(\cdot\mid s,z_1,z_2)$ |
| 第四枚新 token $x_4$ | $p_\theta(\cdot\mid s,x_1,x_2,x_3)$ | $q_{\theta,\phi}(\cdot\mid s,z_1,z_2,z_3)$ |

监督覆盖整个词表的概率。给定一组输入，学生拟合相应教师概率表；
训练集中的各种续写共同决定这种拟合的结果。推理时，验证器根据实际抽出的候选计算目标分布。

训练实现将干净输入和带噪输入拼接为 $[x,z]$，
两份输入使用相同的位置编号 $0,\ldots,T-1$。
块长为 $b$ 时，第 $j$ 个位置所在块的起点为 $g(j)=b\lfloor j/b\rfloor$，
其中 $\lfloor\cdot\rfloor$ 表示向下取整。
注意力读取关系为：

| 查询位置 | 可读的干净输入 | 可读的带噪输入 | LoRA |
|---|---|---|---|
| 干净位置 $j$ | $x_0,\ldots,x_j$ | 空 | 关闭 |
| 带噪位置 $j$ | $x_0,\ldots,x_{g(j)-1}$ | $z_{g(j)},\ldots,z_j$ | 开启 |

序列第 0 项保留为干净起始位置，两份输入在该位置均关闭适配器。
空区间的可读项数为零。两分支的第 $j$ 行均预测下一项。
因而一次配对前向同时提供干净前缀上的教师概率与带噪前缀上的学生概率。

蒸馏概率按完整词表的 softmax 计算。训练目标包含学生到教师的相对熵和逐项绝对差：

```math
D_{\mathrm{KL}}(Q\Vert P)=\sum_v Q(v)\log\frac{Q(v)}{P(v)},
```

```math
\mathcal L_\Delta
=\mathbb E_{x,z}\frac1{|\mathcal I|}
\sum_{j\in\mathcal I}
\left[
\lambda_K D_{\mathrm{KL}}(Q_j\Vert P_j)
+\lambda_1\sum_v|P_j(v)-Q_j(v)|
\right].
```

相对熵衡量两张概率表的差异，参数顺序规定方向。
$\mathcal I$ 是参与损失计算的行集合，$|\mathcal I|$ 是行数，
$\mathbb E$ 表示对样本和噪声取平均。
教师概率在求导时作为常量，学生概率通过 $\phi$ 变化。

绝对差之和为 $2D_{\mathrm{TV}}$，与第 3.3 节的接受率公式直接相连。
热身期使用 $\lambda_K=\lambda_1=1$，后续使用 $\lambda_K=0,\lambda_1=1$，
并随训练增加块长，配置依据见参考文献 [1] 第 3 节。
离线训练读取数据中的干净前缀，实际验证读取候选前缀；
训练分布与生成分布的接近程度影响接受收益。

### 5.4 两次前向与干净缓存

每轮开始时，缓存保存已提交文本 $s$ 中末项 $c$ 之前的基座 KV。
起草前向读取 $[c,z_1,\ldots,z_{b-1}]$，
产生根 token $y_0\sim p(\cdot\mid s)$ 和 $b-1$ 枚候选。

以 $b=4$ 为例，验证前向读取 $[y_0,y_1,y_2,y_3]$，全部关闭 LoRA，得到

```math
\begin{aligned}
p_1&=p(\cdot\mid s,y_0),\\
p_2&=p(\cdot\mid s,y_0,y_1),\\
p_3&=p(\cdot\mid s,y_0,y_1,y_2),\\
p_4&=p(\cdot\mid s,y_0,y_1,y_2,y_3).
\end{aligned}
```

前三行分别验证 $y_1,y_2,y_3$，候选的接受概率为 $\min(1,p_i(y_i)/q_i(y_i))$。
首次拒绝时按残差 $[p_i-q_i]_+$ 归一化抽样；
全部接受时从末行 $p_4$ 抽取额外 token。

设 $A$ 为根之后连续接受的候选数。输出预算充足、该轮继续生成时，

```math
L=2+A,\qquad 0\le A\le b-1.
```

两项固定产出是根 token，以及残差替代 token 或全接受后的额外 token。
例如块长 4、首枚候选被拒绝时，输出根与替代 token，共两枚；
三枚候选全部接受时，输出根、三枚候选和额外 token，共五枚。
结束标记 EOS 和剩余长度预算决定末轮的实际输出数。

缓存保存各个已提交位置的干净计算结果。
起草前向中的 $c$ 在各层均使用基座参数和干净历史，它的新 KV 可以接入历史。
噪声位置的 KV 随本轮丢弃，验证产生的基座 KV 保留至根与接受前缀。
替代 token 或额外 token 成为下一轮的 $c$，其 KV 留到对应前向计算。

因此，下一轮的缓存仍然对应“已提交文本除最后一项”的基座计算。
这个条件在 prefill 后成立，并由每轮的缓存提交持续保持。
从概率角度，根直接服从 $p$，候选经校正后服从 $p$；整轮输出沿实际前缀保持目标分布。

### 5.5 前缀树

线性起草提供一条候选路径；前缀树在若干位置保留多个候选。
每个节点对应一个 token，根到该节点的路径表示一段候选文本。
树注意力允许节点读取公共历史及自身祖先，位置编号按路径深度设置。

当前树实现按起草概率乘积选取预算内的前缀。
目标模型同时计算各节点的下一项分布。
遍历时，输出 token 直接按当前节点的目标分布抽取：
若存在对应子节点，沿该节点继续；走出树时结束本轮。

给定一棵树，每次抽样都来自当前实际前缀的目标分布，
条件概率乘法法则因而给出相同的 AR 输出分布。
树的作用是增加一次验证能够覆盖的路径范围。
更多节点同时增加覆盖机会、验证计算和缓存处理成本。
树验证的固定源码来源见参考文献 [1] 及来源清单。

## 6. 条件修正与在线学习

### 6.1 概率表的在线混合

本节的扩展称为 **OverlapMix（稀疏概率混合）**。
基座与扩散适配器保持固定，学习状态是一组小型混合系数。
已有验证分布提供监督，每完成一组反馈，系数沿着减小概率差异的方向更新。

设一个位置只有“甲”和“乙”两个候选，原起草概率为 $(0.6,0.4)$。
将概率平方并重新归一化，得到更集中的表：

```math
e_{0.5}
=\frac{(0.6^2,0.4^2)}{0.6^2+0.4^2}
=\left(\frac9{13},\frac4{13}\right).
```

原表与这张表各取一半，得到第三张表。
若该位置的目标概率为 $(0.7,0.3)$，相应的接受率为：

| 起草概率 | “甲” | “乙” | $1-D_{\mathrm{TV}}(p,q)$ |
|---|---:|---:|---:|
| 原表 | 0.6000 | 0.4000 | 0.9000 |
| 原表与集中表各占一半 | 0.6462 | 0.3538 | 0.9462 |
| 集中表 | 0.6923 | 0.3077 | 0.9923 |

这里的改善来自概率质量向目标表靠近。
其他前缀可能需要更平缓的概率；验证反馈决定各张表在后续起草中的份额。

### 6.2 候选支撑集与温度表

记原草稿经过实际温度、top-k 和 top-p 处理后的概率为 $q_i^0$。
其正概率 token 构成支撑集

```math
\mathcal S_i=\{v:q_i^0(v)>0\}.
```

top-k 为 $K$ 时，$|\mathcal S_i|\le K$。
每个位置都保留这些 token 的编号和概率。
取 $M$ 个相对温度 $a_1,\ldots,a_M$，定义

```math
e_{ij}(v)=
\frac{q_i^0(v)^{1/a_j}}
{\sum_{u\in\mathcal S_i}q_i^0(u)^{1/a_j}},
\qquad v\in\mathcal S_i.
```

支撑集外的概率为零。$a_j<1$ 提高较大概率的相对份额，$a_j>1$ 使各项更均匀。
$a_j=1$ 对应原表。这个相对温度只调整起草表，目标分布继续使用请求给定的采样设置。

每个深度有一组系数 $w_i=(w_{i1},\ldots,w_{iM})$，满足

```math
w_{ij}\ge0,\qquad \sum_j w_{ij}=1,
\qquad
q_i(v)=\sum_{j=1}^{M}w_{ij}e_{ij}(v).
```

系数非负且总和为 1，保证混合后的概率也非负、总和为 1。
这样的系数集合称为概率单纯形，记作 $\Delta_M$。

实现取 $a=(0.5,0.75,1,1.25,1.5)$。
块长 8 包含 7 个可校准的位置，学习状态共有 $7\times5=35$ 个系数。
初值将全部份额交给 $a=1$ 的原表，其他份额为零。
因此 $q_i=q_i^0$，新增在线状态从原起草行为开始；两份语言模型权重来自已经训练好的检查点。

根 token $y_0$ 继续使用干净的目标概率。
给定当前前缀、噪声及混合系数，其余位置按 $q_i$ 独立抽样。
本节扩展的是跨轮在线校准；第 4.2 节中的块内条件依赖属于另一类模型结构。

### 6.3 验证反馈与更新

验证器沿实际候选前缀给出目标表 $p_i$。
训练观测覆盖已接受位置及首个拒绝位置，每个位置使用本轮抽样时保存的 $q_i$。
将目标概率按候选编号取出，即可计算

```math
\ell_i(w_i)
=D_{\mathrm{TV}}(p_i,q_i)
=1-\sum_{v\in\mathcal S_i}\min(p_i(v),q_i(v)).
```

后一式来自第 3.3 节的重叠质量恒等式。
支撑集外 $q_i(v)=0$，这些位置的重叠质量为零；
目标在支撑集外的质量仍然完整计入损失中的常数项 1。
例如，目标只有 80% 的概率落在 $\mathcal S_i$ 内时，这一支撑集上的接受率上界就是 80%。

固定本次 $p_i$ 与各温度表后，$q_i$ 随系数作线性变化。
函数 $-\min(p,x)$ 是凸函数：沿着两点间的线段，函数值至多为两端函数值的加权平均。
求和仍然保持这一性质，故 $\ell_i$ 关于 $w_i$ 为凸函数。

一个可用的次梯度为

```math
g_{ij}
=-\sum_{v\in\mathcal S_i}
e_{ij}(v)\,\mathbf1[q_i(v)<p_i(v)].
```

次梯度是函数折点处对导数的推广。
当 $q_i(v)<p_i(v)$ 时，增加这项起草概率可以增加重叠质量，故导数取负值；
当 $q_i(v)>p_i(v)$ 时，重叠质量已由 $p_i(v)$ 决定，这一项导数为零。
相等处采用零，是折点允许的选择之一。

每累计 8 个反馈块，对各深度观测到的梯度取平均，记作 $\bar g_{s,i}$。
该深度第 $s$ 次有效更新为

```math
w_{s+1,i}
=\Pi_{\Delta_M}\left(w_{s,i}
-\frac{\eta}{\sqrt{s}}\bar g_{s,i}\right),
\qquad \eta=0.5,\quad s=1,2,\ldots.
```

$\Pi_{\Delta_M}$ 表示把输入向量投影到概率单纯形：
在所有合法系数中，取欧氏距离最近的一组。欧氏距离是逐项差的平方和再开平方。
这一步将更新后的系数恢复为合法的概率份额，计算式见附录 B。

反馈梯度在本轮验证与缓存提交之后累积。
参数与少量梯度统计跨请求保留，每个独立评测流均从原表初值开始。
每轮持有的候选概率、温度表和目标取值随该轮处理结束释放。
更新涉及这些小表及 35 个系数，骨干前向次数仍为每轮两次。

### 6.4 在线概率保持

记第 $t$ 轮开始前的全部历史为 $\mathcal H_t$，
其中包含已提交文本、过去验证反馈和当前系数 $w_t$。
给定 $\mathcal H_t$、本轮噪声以及当前位置之前的候选，
$q_{t,i}$ 就是一张确定的概率表。

令 $\alpha_i(v)=\min(1,p_i(v)/q_{t,i}(v))$。
直接接受 token $v$ 的概率质量为

```math
q_{t,i}(v)\alpha_i(v)=\min(p_i(v),q_{t,i}(v)).
```

拒绝后按正残差归一化抽样，补充的概率质量为 $[p_i(v)-q_{t,i}(v)]_+$。
两部分相加：

```math
\min(p_i(v),q_{t,i}(v))
+[p_i(v)-q_{t,i}(v)]_+
=p_i(v).
```

每一种已知历史和噪声条件下都得到相同的目标表，对这些条件取平均仍然得到 $p_i$。
根与全接受后的额外 token 直接服从对应目标表；
各位置的条件概率相乘，给出固定基座的完整 AR 分布。

实现保存本轮实际用于抽样的概率表，验证完成后更新系数。
因此下一轮使用新系数，本轮校正使用原系数所产生的表。
第 5.4 节的缓存归纳条件也保持原样：提交的 KV 始终来自基座在已接受文本上的计算。

### 6.5 原起草器的比较界

恒等温度表属于混合集合，因此原起草器对应一个合法的固定比较点 $u\in\Delta_M$。
投影更新提供一个可量化的累计比较界。

固定一个深度，把该深度有观测的更新批次编号为 $s=1,\ldots,N$。
令 $f_s(w)$ 为这一批次观测损失的平均值。
各坐标次梯度都在 $[-1,0]$ 内，所以
$\|\bar g_s\|_2^2\le M$。
附录 B 给出

```math
\sum_{s=1}^{N}\bigl[f_s(w_s)-f_s(u)\bigr]
\le
\left(\frac1\eta+\eta M\right)\sqrt N.
```

左边是在同一批实际观测前缀上，在线系数相对固定系数的累计损失差。
除以 $N$ 后，上界随 $1/\sqrt N$ 缩小。
比较点可以选为原表，也可以选为其他固定混合。

这个界比较本次生成过程中观测到的概率表。
整段生成还包含前缀变化、各深度被到达的频率和执行耗时；
相应指标是第 7 节的接受长度与完整 TPS。
原表初值、固定骨干、两次前向和小型状态共同限定了本扩展的改动范围，
配对实验则测量这些改动的实际成本与收益。

验证反馈学习与在线集成的研究背景见参考文献 [3—4]。

## 7. 接受长度与吞吐

### 7.1 连续接受概率

一个位置被接受的概率为 $1-\mathrm{TV}$，整块收益还取决于前面位置均被接受的概率。
令 $A$ 为连续接受的候选数，则

```math
\mathbb E[A]=\sum_{k=1}^{b-1}\Pr(A\ge k).
```

这个等式来自 $A=\sum_{k=1}^{b-1}\mathbf1[A\ge k]$。
例如 $A=2$ 时，求和中的前两项为 1，其余为 0；对各轮取平均即得期望公式。

简化估计可以假设：在此前候选均已接受的条件下，每一深度的接受率都为 $\beta$。
于是第一枚接受的概率为 $\beta$，前两枚均接受的概率为 $\beta^2$，一般有

```math
\Pr(A\ge k)=\beta^k,\qquad
\mathbb E[L]=2+\beta+\beta^2+\cdots+\beta^{b-1}.
```

例如 $b=4,\beta=0.9$ 时，每轮平均输出
$2+0.9+0.81+0.729=4.439$ 枚 token。
若候选扩展到十枚，全部接受的概率为 $0.9^{10}\approx0.349$；
较深位置的贡献由整条前缀的连续接受共同决定。

在 $0\le\beta<1$ 下，等比数列可写为

```math
\mathbb E[L]
=2+\frac{\beta(1-\beta^{b-1})}{1-\beta}.
```

全部接受时 $\beta=1$，每轮输出 $b+1$ 枚；首枚候选总被拒绝时 $\beta=0$，每轮输出两枚。
对应两次解码前向，每次前向的平均产出范围为
$1\le\mathrm{TPF}\le(b+1)/2$，这里沿用完整轮次与充足输出预算的条件。

实际接受率随着文本、噪声、位置和候选变化。
完整计算对每一条候选路径分别加权。
给定本轮文本、噪声、参数和根 token，
令 $d_i(y_{<i})$ 表示位置 $i$ 的准入决定，取 0 或 1。
一条长度为 $k$ 的候选前缀被提出且全部接受的概率质量为

```math
F_k(y_{1:k})
=\prod_{i=1}^{k}
d_i(y_{<i})\min\{q_i(y_i\mid y_{<i}),p_i(y_i\mid y_{<i})\}.
```

每个因子等于“提出概率乘接受概率”。对所有长度为 $k$ 的候选组合求和，得到

```math
\Pr(A\ge k)=\sum_{y_{1:k}}F_k(y_{1:k}),
\qquad
\mathbb E[L]=2+\sum_{k=1}^{b-1}\Pr(A\ge k).
```

固定长度对应所有 $d_i=1$。
上式还解释了逐位置拟合与整轮收益之间的差别：
越深的位置，其贡献受到此前整条路径的接受质量加权。
跨轮统计还对文本、噪声和根 token 取平均。

### 7.2 时间成本

记 AR 平均每 token 耗时为 $C_A$，
投机每轮的起草、验证和其他处理平均耗时分别为 $C_D,C_V,C_H$。
$C_H$ 包含抽样、KV 维护与同步等工作。
共享骨干的起草耗时 $C_D$ 包含完整骨干与 LoRA 的计算。
在稳定负载、完整轮次下，

```math
\mathrm{TPS}_{\mathrm{AR}}\approx\frac1{C_A},
\qquad
\mathrm{TPS}_{\mathrm{spec}}\approx
\frac{\mathbb E[L]}{C_D+C_V+C_H}.
```

TPS 是每秒产生的 token 数。投机相对 AR 的吞吐比为

```math
\mathrm{Speedup}\approx
\frac{\mathbb E[L]C_A}{C_D+C_V+C_H}.
```

分子是普通 AR 产生同样多 token 的时间，分母是投机一轮的时间。
投机吞吐高于 AR 的条件为

```math
\mathbb E[L]C_A>C_D+C_V+C_H.
```

稀疏混合在每个位置处理 $M\times K$ 张量，温度变换、混合与反馈梯度的核心计算量为 $O(bMK)$。
块长 8、$M=5,K=50$ 时，一块的温度表至多包含 $7\times5\times50=1750$ 个数。
每组系数的投影排序成本为 $O(M\log M)$，参数与累积梯度均为 $O(bM)$ 大小。
当前入口从原词表概率中提取候选，并将混合表写回词表形状交给同一个验证器。
候选提取、词表存储、反馈计算与同步也计入完整请求时间；35 个系数刻画学习状态的大小。

设静态与在线版本的平均产出为 $L_0,L_1$，平均轮耗时为 $C_0,C_1$。
在线吞吐提高的条件恰为

```math
\frac{L_1}{L_0}>\frac{C_1}{C_0}.
```

例如每轮产出增加 2%、耗时增加 3%，最终吞吐比为 $1.02/1.03\approx0.990$。

实际请求包含 prefill、EOS 和长度收尾，测量采用总量口径：

```math
\mathrm{TPS}=\frac{N}{T_{\mathrm{request}}},
\qquad
\mathrm{TPS}_{\mathrm{含准备}}
=\frac{N}{T_{\mathrm{request}}+T_{\mathrm{setup}}}.
```

$N$ 是实际返回的 token 总数。
$T_{\mathrm{request}}$ 包含 prefill、生成、反馈、更新和末尾同步；
$T_{\mathrm{setup}}$ 包含图准备与学习器初始化。
模型加载、分词和文本解码的时间另行计量。

TPF 是总输出数除以解码前向次数。
两次前向一轮的路径有 $\mathrm{TPF}\approx\mathbb E[L]/2$。
它衡量前向产出；TPS 同时包含每次前向及其他处理的时间成本。

### 8.2 数值精度

概率保持的证明采用精确算术。
FP32 用 32 位存储一个浮点数，BF16 使用 16 位、保留较少的有效数字。
数值格式、矩阵形状和求和顺序会影响实际浮点结果。
若最大与次大 logit 的间隔为 $\delta$，各 logit 的绝对误差至多为 $\epsilon$，
那么 $\delta>2\epsilon$ 足以保持最大项相同：原来的间隔在最坏情况下缩小 $2\epsilon$。

现有完整基座 FP32 对照覆盖 4 个验证前缀及后续缓存解码。
256 个缓存位置的最大 TV 约为 $2.43\times10^{-6}$，最大项均与外部参照相同。
BF16 的另一次 128 个缓存位置对照中，平均／最大 TV 为 0.01537／0.03796，
最大项在 127 个位置相同。现有 BF16 性能表对应这一近似精度执行分支。

## 附录 A. 离散扩散的逆向转移

设 $s<t$，保留率满足 $a_s>a_t$，令 $\rho=a_t/a_s$。
从 $z_s$ 以概率 $\rho$ 保留原值、以概率 $1-\rho$ 从 $\pi$ 重抽，得到时刻 $t$ 的噪声过程。
已知干净 token $x$，并观察到 $z_t=u$，贝叶斯公式给出

```math
\Pr(z_s=v\mid z_t=u,x)
=
\frac{
[\rho\mathbf1[v=u]+(1-\rho)\pi_u]
[a_s\mathbf1[v=x]+(1-a_s)\pi_v]
}{
\sum_w
[\rho\mathbf1[w=u]+(1-\rho)\pi_u]
[a_s\mathbf1[w=x]+(1-a_s)\pi_w]
}.
```

分子的第一项是“中间 token 为 $v$ 时观察到 $u$ 的概率”，
第二项是“中间 token 原本为 $v$ 的概率”；
分母将所有可能的中间 token 相加，使后验概率归一化。

实际去噪将干净 token 的指示向量替换为模型预测的软概率 $q$，得到插入式逆向核 $R_{s,t}$。
该参数化把软概率代入分子与分母后统一归一化。
记 $R_{0,t}$ 为干净端点核，预测—校正混合为

```math
\Psi_{s,t}
=\kappa R_{s,t}+(1-\kappa)\bigl[a_sR_{0,t}+(1-a_s)\pi\bigr],
\qquad 0\le\kappa\le1.
```

这是概率表的加权平均，各权重之和为 1。
完全噪声到干净端点满足 $a_t=0,a_s=1,\rho=0$。
对可能出现的观察 $u$，逆向核分子为 $\pi_u q(v)$，分母为 $\pi_u$，故

```math
R_{0,1}(v)=q(v),\qquad \Psi_{0,1}(v)=q(v).
```

一步起草因此直接使用模型输出概率。
多步去噪增加中间状态和前向次数；本文的吞吐实验采用一步起草与 AR 验证。

## 附录 B. 单纯形投影与累计比较界

### B.1 概率份额的投影

给定任意向量 $z\in\mathbb R^M$，投影问题为

```math
\min_w\frac12\sum_j(w_j-z_j)^2,
\qquad w_j\ge0,\quad \sum_jw_j=1.
```

平方差惩罚使结果尽量接近 $z$，约束使结果成为概率份额。
最优解可以写成

```math
w_j=\max(z_j-\tau,0),
\qquad \sum_j\max(z_j-\tau,0)=1.
```

所有保留的正项减去同一个阈值 $\tau$，其余项取零。
对正项求导，平方差的导数为 $w_j-z_j$；
和为 1 的约束引入一个公共常数，因此各正项具有相同的 $z_j-w_j=\tau$。
零项则满足 $z_j\le\tau$。

将 $z$ 降序排列为 $z_{(1)}\ge\cdots\ge z_{(M)}$。
设正项数为 $\rho$，由正项之和为 1 得

```math
\tau=\frac{\sum_{j=1}^{\rho}z_{(j)}-1}{\rho},
\qquad
\rho=\max\left\{k:
z_{(k)}-\frac{\sum_{j=1}^{k}z_{(j)}-1}{k}>0
\right\}.
```

这给出了排序、累积求和、选取阈值的直接实现。
例如 $z=(1.1,0.2,-0.1)$，前两项给出 $\tau=0.15$，
结果为 $(0.95,0.05,0)$，三项相加恰为 1。

### B.2 投影更新的距离关系

把一个深度的下标省略，令
$w_{s+1}=\Pi_{\Delta_M}(w_s-\eta_s g_s)$。
投影到闭凸集合后，到集合中任意点 $u$ 的距离至多为投影前的距离，所以

```math
\begin{aligned}
\|w_{s+1}-u\|_2^2
&\le\|w_s-\eta_s g_s-u\|_2^2\\
&=\|w_s-u\|_2^2
-2\eta_s g_s^\top(w_s-u)
+\eta_s^2\|g_s\|_2^2.
\end{aligned}
```

这里 $\|x\|_2^2=\sum_jx_j^2$，$g^\top x=\sum_jg_jx_j$。
移项得到

```math
g_s^\top(w_s-u)
\le
\frac{\|w_s-u\|_2^2-\|w_{s+1}-u\|_2^2}{2\eta_s}
+\frac{\eta_s}{2}\|g_s\|_2^2.
```

凸函数的次梯度满足
$f_s(w_s)-f_s(u)\le g_s^\top(w_s-u)$。
因此右侧也控制一次更新批次上的损失差。

### B.3 累加界

概率单纯形中任意两点的平方距离至多为 $D^2=2$。
将上式对 $s=1,\ldots,N$ 相加，利用步长递减，可以把距离差项整理并界为
$D^2/(2\eta_N)$。
又因为第 6.3 节的每个梯度坐标在 $[-1,0]$ 内，
$\|g_s\|_2^2\le M$，故

```math
\sum_{s=1}^{N}[f_s(w_s)-f_s(u)]
\le
\frac{D^2}{2\eta_N}
+\frac M2\sum_{s=1}^{N}\eta_s.
```

取 $\eta_s=\eta/\sqrt{s}$，并使用
$\sum_{s=1}^{N}s^{-1/2}\le2\sqrt N$，得到

```math
\sum_{s=1}^{N}[f_s(w_s)-f_s(u)]
\le
\left(\frac1\eta+\eta M\right)\sqrt N.
```

实现中的 $f_s$ 是该深度在当前更新窗口内的观测平均损失；
没有观测的深度保持系数与更新编号。
窗口内的所有样本使用同一组系数，平均次梯度就是 $f_s$ 的次梯度，
上述推导因而逐个对应代码中的更新。

## 附录 C. 注意力与缓存计算

矩阵是按行、列排列的数表。线性层用矩阵乘向量，每个输出数都是输入数的加权和；
投影指这种从一组数到另一组数的变换。

注意力把每个位置的表示投影为查询、键和值，分别记为 $Q,K,H_V$。
键与查询的相似程度决定各位置的权重，值提供被加权汇总的内容。
把多个位置排成矩阵，注意力可写为

```math
\operatorname{Attention}(Q,K,H_V)
=\operatorname{softmax}\left(\frac{QK^\top}{\sqrt d}+M\right)H_V.
```

$d$ 是单个注意力头的向量宽度；每个头独立计算一组注意力权重。
$\top$ 表示矩阵转置，即交换行与列；$QK^\top$ 中的每一项是对应查询与键逐项相乘后求和的结果。
softmax 在每一行上归一化，得到该查询对各个键的注意力权重。

矩阵 $M$ 在可读位置取 0，在屏蔽位置取负无穷；屏蔽位置的权重为零。
因果注意力将当前位置右侧的输入屏蔽。位置 $j$ 的表示由位置 $0,\ldots,j$ 确定，
其各层键和值可以存入 KV cache，供后续位置读取。
这一性质也是第 5.4 节保留干净缓存的依据。
