# 自回归语言模型与投机解码

## 1. 下一 token 预测

### 1.1 文本、词表与条件概率

语言模型处理的基本单位称为 token。一个 token 可以表示一个字、词的一部分、标点或特殊符号。
分词器把文本转换为一串整数，每个整数对应词表中的一项。记词表为 $\mathcal V$，大小为 $V$。

一段文本写成 $x_1,\ldots,x_T$，序列前附有起始符 $x_0$。
$x_{<t}$ 表示 $x_0,\ldots,x_{t-1}$，即位置 $t$ 之前的全部内容。
模型给出的条件概率

```math
p_\theta(x_t=v\mid x_{<t})
```

表示：在已有文本为 $x_{<t}$ 的条件下，下一项取词表项 $v$ 的概率。
$\theta$ 汇总模型中的全部参数。对所有 $v$ 求和，概率之和等于 1。

例如，把一句话简化为“我／喜欢／喝／茶”四个 token。
模型在“我／喜欢”之后可能给出“喝”0.6、“吃”0.3、其他项合计 0.1。
按这张概率表抽样，长期约有 60% 的结果为“喝”；一次抽样得到其中一个结果。

向量是一组按顺序排列的数，模型用它表示文本中的信息。
输出层为每个词表项计算一个实数分数，称为 logit。
设这些分数为 $\ell_1,\ldots,\ell_V$，softmax 将它们转换为概率：

```math
p_\theta(v\mid x_{<t})
=\frac{\exp(\ell_v)}{\sum_{u=1}^{V}\exp(\ell_u)}.
```

$\sum$ 表示把下标范围内的各项相加。
$\exp$ 是指数函数，它把实数变为正数；分母把这些正数归一化，使总和为 1。
分数较高的项获得较大的概率。

### 1.2 NTP 训练

下一 token 预测称为 NTP，英文为 next-token prediction。
训练数据提供完整文本，模型根据每个位置的前缀预测下一项。
上面的例子提供了“我”对应“喜欢”、“我／喜欢”对应“喝”等训练样本。

训练损失为

```math
\mathcal L_{\mathrm{NTP}}(\theta)
=-\frac1T\sum_{t=1}^{T}\log p_\theta(x_t\mid x_{<t}).
```

$\log$ 表示自然对数。真实 token 获得的概率越大，负对数越小：
概率从 0.1 提高到 0.8 时，单项损失从约 2.303 降到 0.223。
训练通过调整 $\theta$ 降低样本的平均损失。

参数的导数描述参数发生微小变化时损失的变化率。
把各参数的导数组成向量，得到梯度 $\nabla_\theta\mathcal L$。
最简单的梯度下降更新为
$\theta\leftarrow\theta-\eta\nabla_\theta\mathcal L$，其中 $\eta>0$ 是学习率，控制每次调整的幅度。

训练时，各位置的真实输入都已给定。因果注意力限定位置 $j$ 只读取位置 $0,\ldots,j$，
因此一次模型计算可以同时获得各位置的预测。用真实前缀提供输入的训练方式称为 teacher forcing。

### 1.3 自回归生成

自回归的英文为 autoregressive，简称 AR。整段文本的概率满足条件概率乘法法则：

```math
p_\theta(x_{1:T}\mid x_0)
=\prod_{t=1}^{T}p_\theta(x_t\mid x_{<t}).
```

$\prod$ 表示连乘。生成“我／喜欢／喝／茶”的概率，是生成“我”的概率、
在“我”后生成“喜欢”的概率，以及后续各项条件概率的乘积。

生成过程中，下一次计算的输入包含刚产生的 token。
例如，“我／喜欢”之后抽到“喝”，后续分布的条件就成为“我／喜欢／喝”。
这种逐项形成输入的依赖构成了 AR 解码的串行部分。

推理常使用温度、top-k 和 top-p 调整抽样分布。
正温度 $\tau$ 将 logits 替换为 $\ell/\tau$；较小温度使概率集中。
top-k 保留概率最高的 $k$ 项；top-p 保留降序累计概率达到阈值的最短前缀，包含跨过阈值的那一项。
保留项经过重新归一化，形成实际抽样分布。
贪心解码选择最大 logit，可写成在该项上概率为 1 的特殊分布。

以下记 $p$ 为实际使用的目标分布，包含约定的温度和截断设置。
AR 对照与验证器使用相同的 $p$。

## 2. 模型计算与缓存

一次前向计算是指输入 token 经过各层网络，得到输出 logits 的过程。
嵌入表将 token 编号映射为向量；注意力汇总前缀信息；前馈层变换向量；
输出层把最终向量映射到词表分数。各层的参数与计算构成模型骨干。

矩阵是按行、列排列的数表。线性层用矩阵乘向量，每个输出数都是输入数的加权和；
投影指这种从一组数到另一组数的变换。
注意力把每个位置的表示投影为查询、键和值，分别记为 $Q,K,H_V$。
键与查询的相似程度决定各位置的权重，值提供被加权汇总的内容。
把多个位置排成矩阵，注意力可写为

```math
\operatorname{Attention}(Q,K,H_V)
=\operatorname{softmax}\left(\frac{QK^\top}{\sqrt d}+M\right)H_V.
```

$d$ 是单个注意力头的向量宽度；每个头独立计算一组注意力权重。
$\top$ 表示矩阵转置，即交换行与列；$QK^\top$ 中的每一项是对应查询与键逐项相乘后求和的结果。
矩阵 $M$ 在可读位置取 0，在屏蔽位置取负无穷；屏蔽位置经过 softmax 后的权重为零。
因果注意力中的屏蔽区域位于当前位置的右侧。

KV cache 保存各层已经计算出的历史键和值。
提示文本的首次处理称为 prefill；后续解码直接读取历史 KV，并计算新位置。
因果注意力使历史位置的表示由其自身前缀确定，因此追加 token 后，已有 KV 仍然有效。

单请求解码的短查询往往难以充分利用 GPU。
模型权重和 KV 的读取、矩阵运算、算子启动和同步共同占用时间。
一次处理多个已知位置可以分摊部分成本；实际收益取决于块长、模型大小、并发和执行实现。

## 3. 投机解码

### 3.1 起草与并行验证

投机解码引入一个起草分布 $q$，候选来自 $q$，验证分布来自目标模型 $p$。
已有文本记为 $s$，一组候选为 $y_1,\ldots,y_m$。
候选确定后，目标模型可以用一次因果前向计算整条路径上的条件分布：

```math
p_i(v)=p(v\mid s,y_1,\ldots,y_{i-1}),\qquad i=1,\ldots,m+1.
```

前 $m$ 项用于验证，末项用于候选全部接受时的额外输出。
这些计算使用的是已经给定的候选文本，与 NTP 训练中的并行计算具有相同的输入条件。

起草器可以逐项产生候选，也可以同时计算多个位置的分布。
$q_i$ 表示实际抽取 $y_i$ 时使用的概率表；它可以依赖已有文本、起草噪声和已经抽出的候选。
起草模型与目标模型越接近，候选通常越容易被接受。
起草成本和验证成本决定接受收益能否转化为更高吞吐。[投机解码原论文](https://proceedings.mlr.press/v202/leviathan23a.html)

### 3.2 接受、拒绝与残差分布

考虑一个位置，暂时省略下标。候选 $Y$ 按 $q$ 抽取，其接受概率为

```math
a(Y)=\min\left(1,\frac{p(Y)}{q(Y)}\right).
```

从 $[0,1]$ 均匀抽取随机数 $U$，满足 $U\le a(Y)$ 时接受候选。
例如，某项在 $q$ 中的概率为 0.6，在 $p$ 中为 0.2，
保留它的概率就是 $0.2/0.6=1/3$。
若候选被拒绝，替代 token 按下列残差分布抽取：

```math
r(v)=\frac{[p(v)-q(v)]_+}{Z},
\qquad
Z=\sum_{u\in\mathcal V}[p(u)-q(u)]_+,
\qquad [a]_+=\max(a,0).
```

正差 $[p(v)-q(v)]_+$ 是目标分布中需要补充给 $v$ 的概率质量。
直接接受 $v$ 的概率为

```math
q(v)a(v)=\min(p(v),q(v)).
```

两张概率表总和均为 1，因此正差总量等于负差的绝对值总量。
总拒绝概率恰为 $Z$。用 $\Pr$ 表示事件发生的概率，输出 $v$ 的总概率为

```math
\Pr(\text{输出 }v)
=\min(p(v),q(v))+Zr(v)
=\min(p(v),q(v))+[p(v)-q(v)]_+
=p(v).
```

这给出了概率保持的证明。$q(v)=0$ 的项可以从残差分支获得目标质量；
$p=q$ 时，接受分支已经包含全部质量，$Z=0$。

一个三项词表的例子为：

| 概率质量 | A | B | C |
|---|---:|---:|---:|
| 目标 $p$ | 0.2 | 0.5 | 0.3 |
| 起草 $q$ | 0.6 | 0.1 | 0.3 |
| 直接接受的质量 $\min(p,q)$ | 0.2 | 0.1 | 0.3 |
| 拒绝分支补充的质量 $[p-q]_+$ | 0 | 0.4 | 0 |
| 最终输出质量 | 0.2 | 0.5 | 0.3 |

多个位置按候选顺序验证。首次拒绝后的替代 token 改变了后续条件，当前轮在此结束。
全部候选接受时，末行分布提供一枚额外 token。
上述等式在每个已提交前缀上成立，条件概率乘法法则因此给出整段输出的目标 AR 分布。

这里的无损指目标分布保持相同。随机数的消耗顺序会影响某一次运行得到的具体样本。
精确算术下，贪心分布的验证简化为与目标最大项比较；浮点舍入的影响见第 8 节。

### 3.3 总变差距离与接受率

两张概率表的总变差距离，简称 TV，定义为

```math
D_{\mathrm{TV}}(p,q)=\frac12\sum_v|p(v)-q(v)|.
```

它等于一张概率表转变为另一张表时需要搬动的概率质量。
利用 $\min(a,b)=(a+b-|a-b|)/2$，得到单位置的平均接受率：

```math
\Pr(\text{接受})
=\sum_v\min(p(v),q(v))
=1-D_{\mathrm{TV}}(p,q).
```

前面的例子中，TV 为 0.4，平均接受率为 0.6。
这个等式使用的是同一实际前缀上的 $p,q$；它为起草分布的训练提供了直接的损失依据。

## 4. NTP、MTP 与起草模型

NTP 定义下一项预测的训练目标。输出头是把骨干表示转换成词表分数的模块。
多 token 预测称为 MTP，一种典型形式是在共享骨干上增加多个输出头，
让第 $j$ 个头根据位置 $t$ 的表示预测 $x_{t+j}$：

```math
\mathcal L_{\mathrm{MTP}}
=-\sum_t\sum_{j=1}^{m}\log q_j(x_{t+j}\mid x_{\le t}).
```

多头训练为不同距离的未来 token 提供监督。
这些头可以作为投机解码的起草器，由指定的 NTP 目标分布验证。
不同 MTP 架构对参数共享和头间依赖采用不同设计。
[多 token 预测论文](https://arxiv.org/abs/2404.19737)

投机解码的共同部分是候选与目标验证；各方法的主要差异集中在起草器。

| 方法 | 起草参数和输入 | 候选之间的计算关系 |
|---|---|---|
| [独立小模型](https://proceedings.mlr.press/v202/leviathan23a.html) | 另一套较小的语言模型，读取文本前缀 | 小模型逐项生成，后项读取实际前项 |
| [Medusa](https://arxiv.org/abs/2401.10774) | 目标骨干上的多个预测头；版本间有冻结骨干和联合训练的区别 | 多个头并行提出未来位置的候选，配合树验证 |
| [EAGLE / EAGLE-3](https://arxiv.org/abs/2503.01840) | 轻量起草网络复用目标特征；EAGLE-3 融合多层特征并直接预测 token | 起草网络逐项计算，保留候选间依赖 |
| [层跳跃式自投机](https://arxiv.org/abs/2309.08168) | 起草使用目标模型的部分层，验证使用完整模型 | 部分层组成的起草路径逐项生成 |
| [DFlash](https://arxiv.org/abs/2602.06036) | 独立的轻量块扩散网络，接收目标模型的上下文特征 | 一次前向生成多个位置的分布 |
| [Uno](https://arxiv.org/abs/2609.04010) | 原目标骨干加逐 token 开关的低秩分支 | 一次完整骨干前向产生一块候选分布，原骨干验证 |

[EAGLE 的早期版本](https://arxiv.org/abs/2401.15077)在特征层面自回归，EAGLE-3 使用直接 token 预测和多层特征融合。
DFlash 使用自己的轻量扩散骨干；表中最后一种方法让起草与验证共享完整目标骨干。
共享骨干节省另一套骨干参数的存储，但每次起草仍承担完整层计算和低秩分支计算。

并行起草还涉及两类注意力结构。DFlash 的块内表示可以双向交互；
本项目复刻的分支沿用因果注意力和 NTP 的位置偏移。
在一次并行前向结束时，后续位置的 logits 已经算出，候选 token 则来自随后进行的抽样。
实际抽中的前项与后项预测之间的依赖，是第 6 节条件修正的对象。

表中的方法名称描述架构和训练方式。随机采样的概率保持取决于实际采用的验证规则；
第 3 节的接受与残差校正适用于具有已知条件概率的候选。
树候选的目标路径验证见第 5.5 节。

## 5. 共享骨干的分块扩散起草

Uno 的起草路径与验证路径共享同一组骨干参数，低秩分支在带噪位置开启。

### 5.1 条件低秩分支

原模型的一个线性层写成 $Wh$，其中 $h$ 是输入向量。
低秩适配器把一个大矩阵的变化表示为两个较小矩阵的乘积：

```math
f(h,m)=Wh+m\frac{\alpha}{r_\Delta}B_\Delta A_\Delta h,
\quad
A_\Delta\in\mathbb R^{r_\Delta\times d_{\mathrm{in}}},
\quad
B_\Delta\in\mathbb R^{d_{\mathrm{out}}\times r_\Delta}.
```

$d_{\mathrm{in}},d_{\mathrm{out}}$ 分别是输入、输出向量的长度。
$\mathbb R^{a\times b}$ 表示有 $a$ 行、$b$ 列的实数矩阵。
$m$ 为当前 token 的开关，取 0 或 1；$r_\Delta$ 为中间向量的宽度，它限制了附加矩阵的秩，即独立变换方向的数量。
$\alpha/r_\Delta$ 为缩放系数。
$A_\Delta$ 把输入映射到较窄空间，$B_\Delta$ 把结果映射回输出空间。
新增参数量为 $r_\Delta(d_{\mathrm{in}}+d_{\mathrm{out}})$，
原矩阵的参数量为 $d_{\mathrm{in}}d_{\mathrm{out}}$。[LoRA 论文](https://arxiv.org/abs/2106.09685)

记原骨干参数为 $\theta$，各层低秩参数的集合为 $\phi$。
$m=0$ 对应目标路径，$m=1$ 对应起草路径。
适配器训练通常采用随机的 $A_\Delta$ 和全零的 $B_\Delta$，初始附加量为零。
本项目在注意力的 Q、K、V、输出投影，以及前馈层的三种投影上实现该分支。

这种参数分离使 $\theta$ 决定目标分布，$\phi$ 调整起草分布。
扩散蒸馏期间 $\theta$ 固定，梯度更新 $\phi$。
当前本机实验直接加载已发布的 $\phi$，将其与基座共同冻结。

### 5.2 离散噪声与一步预测

离散扩散用随机替换构造带噪 token。
设原 token 为 $x$，噪声概率表为 $\pi$，时刻 $t$ 的保留率为 $a_t$：

```math
\Pr(z_t=v\mid x)
=a_t\mathbf1[v=x]+(1-a_t)\pi_v,
\qquad a_0=1,\quad a_1=0.
```

指示函数 $\mathbf1[\cdot]$ 在括号内条件成立时取 1，其余情况取 0。
$a_t$ 从 1 降到 0 时，原 token 的影响逐渐被噪声取代。
$\pi$ 可以集中在一个掩码符号上，也可以在一组普通 token 上均匀分布。
这里使用均匀替换；本机公开权重的起草噪声范围为整数 $[1,64256)$。

一步起草直接把完全带噪的块映射为干净 token 的概率。
“去噪”描述训练中的输入与预测关系；输入位置 $j$ 的 logits 仍然预测下一位置。
完整噪声到干净端点的 $\Psi$ 转移简化为模型输出的概率表，推导见附录 A。

### 5.3 配对蒸馏

蒸馏用一个模型的概率表监督另一个模型。
这里目标路径是教师，开启低秩分支的路径是学生。教师提供整个词表的软概率。

取长度为 $T$ 的干净输入 $x_0,\ldots,x_{T-1}$，以及对应的带噪输入 $z_0,\ldots,z_{T-1}$。
两者拼接为 $[x,z]$，位置编号各为 $0,\ldots,T-1$。
设块长为 $b$，位置 $j$ 所在块的起点为 $g(j)=b\lfloor j/b\rfloor$，
其中 $\lfloor\cdot\rfloor$ 表示向下取整。注意力读取关系为：

| 查询位置 | 可读的干净输入 | 可读的带噪输入 | 低秩分支 |
|---|---|---|---|
| 干净位置 $j$ | $x_0,\ldots,x_j$ | 空 | 关闭 |
| 带噪位置 $j$ | $x_0,\ldots,x_{g(j)-1}$ | $z_{g(j)},\ldots,z_j$ | 开启 |

序列第 0 项保留为干净起始位置，两份输入在该位置均关闭适配器。
表中空区间的可读项数为零。两个分支的第 $j$ 行都预测下一项 $x_{j+1}$。

记教师和学生在监督行上的概率为 $P_j,Q_j$。教师读取真实块内前缀；
学生读取已完成的干净块和当前噪声块。单次配对前向同时提供这两组概率。

论文的训练目标包含学生到教师的相对熵，以及逐项绝对差：

```math
D_{\mathrm{KL}}(Q\Vert P)=\sum_v Q(v)\log\frac{Q(v)}{P(v)},
\qquad
\mathcal L_\Delta
=\mathbb E_{x,z}\frac1{|\mathcal I|}
\sum_{j\in\mathcal I}
\left[
\lambda_K D_{\mathrm{KL}}(Q_j\Vert P_j)
+\lambda_1\sum_v|P_j(v)-Q_j(v)|
\right].
```

$\mathcal I$ 是参与损失计算的行集合，$|\mathcal I|$ 是行数，$\mathbb E$ 表示对样本与噪声取平均。
相对熵衡量两张概率表的差异，参数顺序规定了方向。
绝对差之和等于 $2D_{\mathrm{TV}}$。
教师概率在求导时作为常量，学生概率通过 $\phi$ 变化。

热身期使用 $\lambda_K=\lambda_1=1$，后续使用 $\lambda_K=0,\lambda_1=1$。
块长课程逐步增加学生预测的距离。
训练数据提供的上下文决定蒸馏损失覆盖的分布；实际推理中的验证器读取当前候选前缀。
离线损失与生成接受长度的联系因此还受上下文分布影响。
[原论文第 3 节](https://arxiv.org/pdf/2609.04010)

### 5.4 两次前向与干净缓存

设已提交文本为 $s$，最后一项为 $c$，缓存保存 $c$ 之前的全部基座 KV。
一个长度为 $b$ 的起草输入为 $[c,z_1,\ldots,z_{b-1}]$。

| 前向 | 输入 | 低秩开关 | 输出 |
|---|---|---|---|
| 起草 | $c,z_1,\ldots,z_{b-1}$ | $0,1,\ldots,1$ | 根 token 的目标分布，以及 $b-1$ 个起草分布 |
| 验证 | $y_0,y_1,\ldots,y_{b-1}$ | 全部为 0 | 候选条件分布，以及末行的额外输出分布 |

$c$ 是旧文本中的 token，$y_0$ 是本轮新增的第一枚 token。
根位置关闭适配器，因果注意力使它只读取干净历史与自身。
因此其 logits 等于基座在前缀 $s$ 上的 logits：

```math
y_0\sim p(\cdot\mid s),
\qquad
y_i\sim q_i(\cdot\mid s,z),\quad 1\le i<b.
```

给定噪声 $z$，各起草概率表已由一次前向确定，线性采样独立抽取后续候选。
其联合分布为 $\prod_{i=1}^{b-1}q_i(y_i\mid s,z)$。
验证器读取实际候选，得到
$p_i(\cdot)=p(\cdot\mid s,y_0,\ldots,y_{i-1})$，
并用第 3 节的校正规则决定输出。

缓存只保留目标路径的内容。起草前向中，$c$ 在每一层都由干净输入和基座参数计算，
它的新 KV 可以接入历史；噪声位置的 KV 随本轮丢弃。
验证产生完整候选路径的基座 KV，最终保留已提交的根与接受前缀。
替代 token 或额外 token 成为下一轮的 $c$，其 KV 留到对应前向计算。

由此，每轮开始的缓存都等于基座对“已提交文本除最后一项”的计算结果。
这个条件从 prefill 成立，并在每轮提交后延续。

设 $A$ 为根之后连续接受的候选数。输出预算充足且该轮继续生成时，输出数为

```math
L=2+A,\qquad 0\le A\le b-1.
```

两项固定产出分别为根 token，以及拒绝时的替代 token 或全接受时的额外 token。
例如 $b=4$ 时，一轮输出 2 至 5 枚 token，消耗两次骨干前向。
结束标记 EOS 表示文本生成结束；它与剩余长度预算共同决定末轮的实际输出数。

### 5.5 前缀树

线性起草提供一条候选路径；前缀树在若干位置保留多个候选。
每个节点对应一个 token，根到该节点的路径表示一段候选文本。
树注意力允许节点读取公共历史及自身祖先，位置编号按路径深度设置。

当前树实现按起草概率乘积选取预算内的前缀。
目标模型同时计算各节点的下一项分布。
遍历时，输出 token 直接按当前节点的目标分布抽取：
若存在对应子节点，沿该节点继续；走出树时结束本轮。

给定一棵树，每次抽样都来自当前实际前缀的目标分布，
条件概率乘法法则因而给出相同的 AR 输出分布。
树的作用是增加一次验证能够覆盖的路径范围。
更多节点同时增加覆盖机会、验证计算和缓存处理成本。
[固定版本的树验证实现](https://github.com/ifm-ai/uno/blob/ed2ee36bb7a3aea8732ebc635b3f09490a032ea3/nano_vllm_uno/engine/two_pass_decoding.py)

## 6. 条件修正与在线学习

### 6.1 块内依赖与 PrefixRelay

设某个前缀有两种等概率续写：“喝／茶”和“吃／饭”。
独立预测时，首位置在“喝／吃”间均分，次位置在“茶／饭”间均分。
独立抽样会产生四种组合，各占四分之一，其中“喝／饭”和“吃／茶”偏离了原来的成对关系。

[DSpark](https://arxiv.org/html/2607.05147v1) 在并行骨干之后加入轻量串行模块，
用已经抽出的前项修正后项分数，并结合置信度安排验证长度。
其 Markov 版本只使用上一枚 token；RNN 版本还维护块内历史状态。

本项目的 PrefixRelay 将低秩 Markov 修正接到第 5 节的共享骨干起草器上。
记第 $i$ 个起草位置的 logits 为 $u_i$，末层特征为 $h_i$，
新增两个矩阵 $E\in\mathbb R^{V\times r_h}$、$R\in\mathbb R^{r_h\times V}$：

```math
\widetilde u_i=u_i+E[y_{i-1}]R,
\qquad
\widetilde q_i=\mathcal T(\widetilde u_i),
\qquad
y_i\sim\widetilde q_i.
```

$E[y]$ 表示取矩阵 $E$ 的第 $y$ 行，即该 token 的低维向量；
乘以 $R$ 得到整个词表的修正分数。
$\mathcal T$ 表示实际采用的温度、截断和归一化。
根 token $y_0$ 保持目标抽样，其余候选按实际前项逐项修正。

并行骨干提供固定的 $u_i,h_i$，小头提供候选之间的条件联系。
联合概率相应变为

```math
\widetilde Q(y_{1:b-1}\mid s,y_0,z)
=\prod_{i=1}^{b-1}
\widetilde q_i(y_i\mid s,z,y_{i-1}).
```

逐个对末尾变量求和，每个条件概率表的和均为 1，整个联合概率的和也为 1。
$R$ 采用零初始化，初始修正为零；
$E$ 可采用随机初始化，或由冻结基座的 token 嵌入投影得到。

### 6.2 验证反馈与小头损失

在线学习的训练样本来自实际生成中的验证反馈。
本项目保存已接受位置及首个拒绝位置的
$(u_i,h_i,y_{i-1},p_i)$。
这些位置的目标分布对应实际到达的前缀；首次拒绝之后的目标行对应已经偏离的候选路径。

新增置信度头预测单位置平均接受率。设特征宽度为 $d$，其计算为

```math
\bar h_i=
\frac{h_i}{\sqrt{d^{-1}\sum_{j=1}^{d}h_{ij}^2+\epsilon}},
\qquad
\widehat c_i=
\sigma\left(w^\top[\bar h_i;E[y_{i-1}]]+a\right),
\qquad \sigma(x)=\frac1{1+e^{-x}}.
```

归一化使特征保持适当尺度，$\epsilon>0$ 稳定分母；
方括号和分号表示向量拼接；$w,a$ 是新增参数。
sigmoid 函数 $\sigma$ 把实数分数映射到 0 与 1 之间。

单位置监督值取 $c_i^\star=1-D_{\mathrm{TV}}(p_i,\widetilde q_i)$。
令 $\psi=(E,R,w,a)$ 汇总小头参数，反馈损失为

```math
\mathcal L_{\mathrm{head}}
=\frac1{|\mathcal I|}\sum_{i\in\mathcal I}
\left[
D_{\mathrm{TV}}(p_i,\widetilde q_i)
+\lambda\,\mathrm{BCE}(\widehat c_i,\operatorname{sg}[c_i^\star])
\right],
```

```math
\mathrm{BCE}(c,t)=-t\log c-(1-t)\log(1-c).
```

$\mathrm{BCE}$ 是二元交叉熵，$t$ 可取 0 与 1 之间的软目标；
$\operatorname{sg}$ 表示求导时将该目标当作常量。
TV 项训练候选分布，BCE 项训练置信度。

基座 $\theta$ 与扩散适配器 $\phi$ 共同冻结，$u_i,h_i,p_i$ 及已采样 token 在求导时作为常量。
梯度计算只涉及小头。该损失优化给定观测前缀上的分布拟合；
接受长度和 TPS 刻画由新参数产生的完整生成效果。

实现每累计 $S$ 个反馈块执行一次 AdamW 更新。
AdamW 根据梯度及梯度平方的历史加权平均调整各参数的步长，并用权重衰减抑制参数过大；
转移矩阵与置信度层采用独立学习率。
小头与优化器状态跨请求保留，待训练反馈在请求结束时释放。
验证反馈用于起草器更新的研究起点包括 [Online Speculative Decoding](https://arxiv.org/abs/2310.07177)。

### 6.3 置信度截断

在第 $i$ 枚候选的抽样时刻，已有信息包含骨干特征和 $y_{i-1}$。
定义前缀分数

```math
\widehat S_i=\prod_{j=1}^{i}\widehat c_j.
```

当前及此前位置均通过阈值 $\gamma$ 时，位置 $i$ 纳入候选；
$\widehat S_i<\gamma$ 时，候选扩展在该位置结束。
验证器接收已经纳入的前缀，包含根 token。
纳入 $n$ 枚后续候选时，实际验证长度为 $n+1$。

准入决定发生在当前 token 抽样之前，因此该位置采用的条件分布仍为已记录的 $\widetilde q_i$。
$\widehat S_i$ 是由置信度构造的调度分数，校准依据是实际前缀存活计数。
本项目采用单请求阈值规则；DSpark 还包含面向多请求和硬件负载的调度器。

### 6.4 在线更新与概率保持

在第 $t$ 轮开始时，已提交文本、过去反馈和参数 $\psi_t$ 都已确定。
给定本轮噪声及当前候选之前的信息，$\widetilde q_{t,i}$ 是一张确定的概率表。
第 3.2 节的恒等式对这张表成立：

```math
\min(p_i(v),\widetilde q_{t,i}(v))
+[p_i(v)-\widetilde q_{t,i}(v)]_+
=p_i(v).
```

被纳入的位置按该表抽样并校正；在抽样前结束候选扩展的位置直接使用目标分布。
两种情况都产生 $p_i$，对历史和噪声的各种取值加权后仍得到 $p_i$。

本轮验证读取抽样时保存的 $\widetilde q_{t,i}$。
参数更新发生于本轮验证及缓存提交之后，新参数供后续轮次使用。
逐轮应用相同的条件概率恒等式，在线学习下的输出分布仍为固定基座的 AR 分布。

这一结论来自候选概率与校正概率的配对。
在线学习的效果表现为接受长度和执行成本的变化。
训练对象若扩展到原低秩参数 $\phi$，相同概率论证仍适用；相应反向计算还会经过骨干层。
当前实验的训练对象为 $\psi$。

## 7. 接受长度与吞吐

### 7.1 连续接受概率

一个位置被接受的概率为 $1-\mathrm{TV}$，整块收益还取决于前面位置均被接受的概率。
令 $A$ 为连续接受的候选数，则

```math
\mathbb E[A]=\sum_{k=1}^{b-1}\Pr(A\ge k).
```

这个等式来自 $A=\sum_{k=1}^{b-1}\mathbf1[A\ge k]$。
例如 $A=2$ 时，求和中的前两项为 1，其余为 0；对各轮取平均即得期望公式。

给定本轮文本、噪声、参数和根 token，
令 $d_i(y_{<i})$ 表示位置 $i$ 的准入决定，取 0 或 1。
一条长度为 $k$ 的候选前缀被提出且全部接受的概率质量为

```math
F_k(y_{1:k})
=\prod_{i=1}^{k}
d_i(y_{<i})\min\{q_i(y_i\mid y_{<i}),p_i(y_i\mid y_{<i})\}.
```

每个因子等于“提出概率乘接受概率”。对所有长度为 $k$ 的候选组合求和，得到

```math
\Pr(A\ge k)=\sum_{y_{1:k}}F_k(y_{1:k}),
\qquad
\mathbb E[L]=2+\sum_{k=1}^{b-1}\Pr(A\ge k).
```

固定长度对应所有 $d_i=1$。
上式还解释了逐位置拟合与整轮收益之间的差别：
越深的位置，其贡献受到此前整条路径的接受质量加权。
跨轮统计还对文本、噪声和根 token 取平均。

### 7.2 时间成本

记 AR 平均每 token 耗时为 $C_A$，
投机每轮的起草、验证和其他处理平均耗时分别为 $C_D,C_V,C_H$。
$C_H$ 包含抽样、KV 维护与同步等工作。
在稳定负载、完整轮次下，

```math
\mathrm{TPS}_{\mathrm{AR}}\approx\frac1{C_A},
\qquad
\mathrm{TPS}_{\mathrm{spec}}\approx
\frac{\mathbb E[L]}{C_D+C_V+C_H}.
```

TPS 是每秒产生的 token 数。投机吞吐高于 AR 的条件为

```math
\mathbb E[L]C_A>C_D+C_V+C_H.
```

小头增加前向成本；反馈保存、反向和参数更新增加在线成本。
两个转移矩阵共有 $2Vr_h$ 个参数，每个候选的转移乘法约需 $2Vr_h$ 次浮点运算。
$V=64256,r_h=64$ 时，转移矩阵含 8,224,768 个参数；
加上宽度为 1536 的置信度头，共 8,226,369 个参数。
“可训练参数少”对应较小的新增模型，实际延迟还取决于词表处理和执行调度。

设静态与在线版本的平均产出为 $L_0,L_1$，平均轮耗时为 $C_0,C_1$。
在线吞吐提高的条件恰为

```math
\frac{L_1}{L_0}>\frac{C_1}{C_0}.
```

例如每轮产出增加 2%、耗时增加 3%，最终吞吐比为 $1.02/1.03\approx0.990$。

实际请求包含 prefill、EOS 和长度收尾，测量采用总量口径：

```math
\mathrm{TPS}=\frac{N}{T_{\mathrm{request}}},
\qquad
\mathrm{TPS}_{\mathrm{含准备}}
=\frac{N}{T_{\mathrm{request}}+T_{\mathrm{setup}}}.
```

$N$ 是实际返回的 token 总数。
$T_{\mathrm{request}}$ 包含 prefill、生成、反馈、更新和末尾同步；
$T_{\mathrm{setup}}$ 包含图准备与学习器初始化。
模型加载、分词和文本解码的时间另行计量。

TPF 是总输出数除以解码前向次数。
两次前向一轮的路径有 $\mathrm{TPF}\approx\mathbb E[L]/2$。
它衡量前向产出；TPS 同时包含每次前向及其他处理的时间成本。

### 8.2 数值精度

概率保持的证明采用精确算术。
FP32 用 32 位存储一个浮点数，BF16 使用 16 位、保留较少的有效数字。
数值格式、矩阵形状和求和顺序会影响实际浮点结果。
若最大与次大 logit 的间隔为 $\delta$，各 logit 的绝对误差至多为 $\epsilon$，
那么 $\delta>2\epsilon$ 足以保持最大项相同：原来的间隔在最坏情况下缩小 $2\epsilon$。

现有完整基座 FP32 对照覆盖 4 个验证前缀及后续缓存解码。
256 个缓存位置的最大 TV 约为 $2.43\times10^{-6}$，最大项均与外部参照相同。
BF16 的另一次 128 个缓存位置对照中，平均／最大 TV 为 0.01537／0.03796，
最大项在 127 个位置相同。现有 BF16 性能表对应这一近似精度执行分支。

## 附录 A. 离散扩散的逆向转移

设 $s<t$，保留率满足 $a_s>a_t$，令 $\rho=a_t/a_s$。
从 $z_s$ 以概率 $\rho$ 保留原值、以概率 $1-\rho$ 从 $\pi$ 重抽，得到时刻 $t$ 的噪声过程。
已知干净 token $x$，并观察到 $z_t=u$，贝叶斯公式给出

```math
\Pr(z_s=v\mid z_t=u,x)
=
\frac{
[\rho\mathbf1[v=u]+(1-\rho)\pi_u]
[a_s\mathbf1[v=x]+(1-a_s)\pi_v]
}{
\sum_w
[\rho\mathbf1[w=u]+(1-\rho)\pi_u]
[a_s\mathbf1[w=x]+(1-a_s)\pi_w]
}.
```

分子的第一项是“中间 token 为 $v$ 时观察到 $u$ 的概率”，
第二项是“中间 token 原本为 $v$ 的概率”；
分母将所有可能的中间 token 相加，使后验概率归一化。

实际去噪将干净 token 的指示向量替换为模型预测的软概率 $q$，得到插入式逆向核 $R_{s,t}$。
该参数化把软概率代入分子与分母后统一归一化。
记 $R_{0,t}$ 为干净端点核，预测—校正混合为

```math
\Psi_{s,t}
=\kappa R_{s,t}+(1-\kappa)\bigl[a_sR_{0,t}+(1-a_s)\pi\bigr],
\qquad 0\le\kappa\le1.
```

这是概率表的加权平均，各权重之和为 1。
完全噪声到干净端点满足 $a_t=0,a_s=1,\rho=0$。
对可能出现的观察 $u$，逆向核分子为 $\pi_u q(v)$，分母为 $\pi_u$，故

```math
R_{0,1}(v)=q(v),\qquad \Psi_{0,1}(v)=q(v).
```

一步起草因此直接使用模型输出概率。
多步去噪增加中间状态和前向次数；本文的吞吐实验采用一步起草与 AR 验证。

## 附录 B. 冻结特征与小头计算

设冻结部分产生特征 $H=F(x;\theta)$，可训练部分产生 logits $\ell=G(H;\psi)$。
损失对 logits 的梯度记为 $g$。
链式法则为

```math
\nabla_\psi\mathcal L
=
\left(\frac{\partial G}{\partial\psi}\right)^\top g
+
\left(\frac{\partial H}{\partial\psi}\right)^\top
\left(\frac{\partial G}{\partial H}\right)^\top g.
```

$\partial G/\partial H$ 表示输出各项对输入各项的导数矩阵。
冻结特征与 $\psi$ 无关，所以 $\partial H/\partial\psi=0$。
复用同一特征并对可训练部分求导，与完整重算中该参数子集的梯度相同。
原适配器的末层续训复用冻结前段特征；小头学习复用整个冻结起草骨干的 logits 与末层特征。

词表输出逐行计算。设 $S$ 表示选取有监督的行，$N$ 表示逐行归一化，$W_{\mathrm{out}}$ 为词表矩阵，
则

```math
S\bigl(N(H)W_{\mathrm{out}}^\top\bigr)
=N(SH)W_{\mathrm{out}}^\top.
```

等式两侧给出相同的监督 logits，右侧的词表乘法只处理有监督的行。
只依赖这些行的损失具有相同梯度。

小头 GPU 图采用指数竞争抽样。为各词表项生成独立的 $e_v\sim\mathrm{Exp}(1)$，
选择 $q(v)/e_v$ 最大的项。$\mathrm{Exp}(1)$ 是速率为 1 的指数分布，可理解为随机等待时间。
$q(v)>0$ 时，$e_v/q(v)$ 的等待速率为 $q(v)$，它最早出现的概率为

```math
\int_0^\infty q(v)e^{-q(v)t}
\prod_{u\ne v}e^{-q(u)t}\,dt
=\int_0^\infty q(v)e^{-t}\,dt
=q(v).
```

$\int_0^\infty$ 表示汇总所有可能等待时刻的概率密度；等式中的乘积表示其余项同时晚于时刻 $t$。
$q(v)=0$ 的项对应无限等待时间。
因此该抽样与按 $q$ 抽取 token 具有相同分布，能够与块内条件修正共同录入 GPU 图。
