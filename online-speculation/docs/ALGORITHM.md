# 分块起草、验证解码与在线蒸馏：从概率基础到完整管线

本文随实现和实验结果持续更新。
命令见 [RUNNING.md](RUNNING.md)，实现目录见 [README](../README.md)。

**来源与归属。** 条件低秩适配、块去噪蒸馏和两遍验证解码的研究起点是
[Uno：Unlocking Lossless Speedups in LLMs via Discrete Diffusion](https://arxiv.org/abs/2609.04010)。
本项目据此编写模型、训练与推理实现，推导概率关系，并用可枚举问题、数值微分和外部模型对照验证。

主线是：**已有自回归基座 → 从零初始化草稿适配器 → 离线蒸馏 → 验证解码 → 推理中的适配器续训**。
基座采用预训练权重；适配器从随机初始化开始离线学习，随后在推理请求中继续训练。

## 1. 我们究竟要改变什么

token 是词表中的一个编号，可能表示一个字、词的一部分或标点。语言模型看到的是整数序列。
给定已经确定的文本 h，模型给出“下一个 token 是什么”的概率。
设词表为 $\mathcal V=\{0,\ldots,V-1\}$，基座概率记为 $p_\theta(v\mid h)$：

- $\theta$ 是始终冻结的基座权重。
- p 是最终输出应服从的目标概率表。
- $q_\phi$ 是草稿概率表，由可训练参数 $\phi$ 控制，用来近似目标 p。

例如词表为 A、B、C，$p=(0.2,0.5,0.3)$ 表示反复抽样时，长期频率约为 20%、50%、30%。
单次抽样按这张表随机选择一个 token。

模型先输出任意实数 $l_v$，称为 logits，再变成概率：

```math
p_v=\frac{\exp(l_v)}{\sum_{u\in\mathcal V}\exp(l_u)}.                  \tag{1}
```

这叫 softmax，所有概率经过分母归一化后和为 1。温度 $\tau>0$ 时用 $l_v/\tau$；温度为零另行定义为贪心：
选最大 logit，概率表变成一个 1 和其余 0。top-k 保留最大的 k 项；top-p 保留按概率降序累计达到
阈值的最短前缀，再归一化。实现保留使累计概率跨过阈值的那一项。

候选抽样与概率校正使用相同的温度和截断设置。
[sampling.py](../src/blockspec/sampling.py) 在抽样之前构造这张概率表。
贪心是一个可以化简的特例：最大项的概率为 1，其余项为 0，最终输出等于老师的最大项。
因此可以用 argmax 直接实现这个特例。
当前 AR、线性和树解码都直接计算 argmax；小词表穷举检验了化简前后逐步结果一致。
相等的最大值按同一个 argmax 顺序打破平局。

## 2. 自回归为什么串行，验证为什么可以并行

自回归（AR）是逐项生成，每一步依赖之前的输出。乘法法则给出：

```math
p_\theta(y_1,\ldots,y_n\mid h)
=\prod_{i=1}^n p_\theta(y_i\mid h,y_1,\ldots,y_{i-1}).                \tag{2}
```

第二项的条件包含第一项，所以正常生成先得到 $y_1$，再确定第二步输入。
给定候选 A、B、C，可以把它们一次送进模型，让每个位置按因果规则读取自己的前缀。
一遍前向就得到这条候选路径上所有位置的“下一项概率”。

这个读取规则叫因果注意力：每个位置读取自身及其之前的输入。
因此“先起草后续多项，再一起验证”有机会减少串行前向次数。

**输入位置 j 的 logits 预测 j+1 的 token。**
干净分支、带噪分支和验证分支都保持这一约定。

### 2.1 模型中的矩阵在做什么

嵌入表把 token 编号变成向量 x，线性层是 $Wx$。注意力产生查询、键、值三类向量：

```math
Q=XW_Q^\top,\quad K=XW_K^\top,\quad V=XW_V^\top,
\qquad H=\operatorname{softmax}\left(\frac{QK^\top}{\sqrt d}+M\right)V. \tag{3}
```

这里 $\top$ 表示矩阵转置。可读位置在 M 中取 0，屏蔽位置取负无穷，softmax 后屏蔽位置的权重为零。
多头注意力并行使用多组这样的向量；GQA 让多个查询头共享键和值，减少缓存。

RMSNorm 按均方根缩放向量，再乘权重：

```math
\operatorname{RMSNorm}(x)_i
=w_ix_i\left(\frac1d\sum_j x_j^2+\epsilon\right)^{-1/2}.              \tag{4}
```

前馈层为 $W_{down}[\operatorname{SiLU}(W_{gate}x)\odot(W_{up}x)]$，
$\odot$ 是逐项相乘，$\operatorname{SiLU}(a)=a/(1+e^{-a})$；残差连接把子层输出加回输入。
这些运算组成了本项目的 Transformer。

位置编码对成对分量做旋转，角度为“位置 × 频率”，基础频率 $\omega_j=\vartheta^{-2j/d}$。
当前本地基座使用 YaRN：按维度平滑混合原频率和除以扩展倍数后的频率，并应用配置中的幅度因子。
频率保持 FP32，RMSNorm 的舍入位置按基座架构设置。
[model.py](../src/blockspec/model.py) 实现这些运算，测试另外用显式注意力方程和小型 Qwen3 作数值参照。

位置旋转还有一个直接的执行优化。记 $c_{ij}=\cos(i\omega_j)$、$s_{ij}=\sin(i\omega_j)$，
那么任一层向量的旋转就是 $x\odot c+\operatorname{rotate\_half}(x)\odot s$，再包含配置要求的幅度缩放。
c、s 由位置与固定频率确定，所有层共享同一份值。
因此一次前向中可以先算一份 c、s，让所有层的 Q、K 共用；位置旋转系数的计算次数从每层两次减少为整个前向一次。
对参数求导时 c、s 是相同的常数，因此共享计算得到相同梯度。
实现还保留独立旋转函数作参照；FP32、FP64、BF16 和 autocast 测试逐项核对 logits、KV、梯度及后段重放。

## 3. 同一个基座怎样变成草稿模型

把原线性层扩展成：

```math
f_\phi(x,m)=Wx+msBAx,\quad s=\alpha/r,
\qquad A\in\mathbb R^{r\times d_{in}},\ B\in\mathbb R^{d_{out}\times r}. \tag{5}
```

$m=0$ 关适配器，$m=1$ 开适配器。r 是秩，远小于输入、输出维度时，新增参数为
$r(d_{in}+d_{out})$，而原矩阵有 $d_{out}d_{in}$ 项。
低秩参数化来自 [LoRA](https://arxiv.org/abs/2106.09685)，按 token 开关用于隔离干净和带噪计算。

A 初始化为小随机矩阵、B 初始化为零，因此最初 $BA=0$。适配器接下来要学习根据前缀和噪声预测后续。
默认每层 Q、K、V、O、gate、up、down 七种投影都有适配器，草稿与验证共享基座。
起草时种子位置关，噪声位置开；验证时全部关。

若损失对层输出的导数为 g，链式法则给出：

```math
\nabla_B L=ms\,g(Ax)^\top,\qquad
\nabla_A L=ms\,B^\top gx^\top.                                      \tag{6}
```

初始化 $B=0$ 时，首步 A 的梯度为零，B 的梯度由 g 和 Ax 决定。数值微分测试通过对参数做小的正负扰动，
比较损失差商与自动求导，检验这个公式和实际低秩实现一致。

## 4. 离散噪声、逆向后验与一步去噪

离散扩散用随机 token 逐渐替换原 token，再从上下文预测干净分布。
设原 token 是 x，噪声概率表为 $\pi$，保留率 $a_t\in[0,1]$ 随时间 t 下降：

```math
\Pr(z_t=v\mid x)=a_t\mathbf1[v=x]+(1-a_t)\pi_v.                       \tag{7}
```

$\mathbf1$ 为指示函数：条件成立取 1，其余情况取 0。实现方法是以概率 $a_t$ 保留 x，以概率 $1-a_t$ 按 $\pi$ 重抽。
重抽也可能抽回 x，因此最终与 x 相同的概率为 $a_t+(1-a_t)\pi_x$。
均匀 $\pi$、$a_t=0$ 对应从全词表抽纯噪声。

### 4.1 贝叶斯公式一步一步算回去

较干净时刻 s 和较噪时刻 t 满足 $a_s>a_t$，令 $\rho=a_t/a_s$。
从 $z_s$ 再以保留率 $\rho$ 做一次相同的替换，得到式 (7) 的边缘分布。
已观察到 $z_t=u$，中间 token 为 v 的后验是：

```math
\Pr(z_s=v\mid z_t=u,x)=
\frac{[\rho\mathbf1[v=u]+(1-\rho)\pi_u]
      [a_s\mathbf1[v=x]+(1-a_s)\pi_v]}
     {\sum_w[\rho\mathbf1[w=u]+(1-\rho)\pi_u]
      [a_s\mathbf1[w=x]+(1-a_s)\pi_w]}.                              \tag{8}
```

分子的第一项是“假设中间为 v，看到 u 的可能性”，第二项是“中间原本为 v 的可能性”。
分母对所有中间状态求和，使结果总和为 1。这就是有限词表中的贝叶斯公式。

实际生成时，用模型预测的软向量 $q_\phi$ 替代 x 的 one-hot 向量，定义插入式逆向核。
one-hot 输入对应精确贝叶斯后验；软向量输入对应这种选定的参数化。
插入式核先在式 (8) 中代入软向量，再对 v 归一化；分子和分母都使用代入后的值。

### 4.2 预测—校正混合为什么退化成一次前向

令 $R_{s,t}$ 表示式 (8) 的插入式核，$R_{0,t}$ 表示其中 $a_s=1$ 的干净预测。混合核写成：

```math
\Psi_{s,t}=\kappa R_{s,t}+(1-\kappa)[a_sR_{0,t}+(1-a_s)\pi],
\qquad 0\le\kappa\le1.                                               \tag{9}
```

两个概率向量的凸组合中，各项都在 $[0,1]$ 内，总和为 1。特别地，完全噪声一步回到干净端点 $a_t=0,a_s=1$ 时，
式 (8) 第一项在各个 v 上均为 $\pi_u$，归一化时约去这个共同因子，因此：

```math
R_{0,1}=q_\phi,\qquad\Psi_{0,1}=q_\phi.                              \tag{10}
```

因此主加速路径通过一次学生前向得到草稿分布。
[diffusion.py](../src/blockspec/diffusion.py) 实现式 (7)–(10)，测试穷举三项词表中的中间状态。

## 5. 离线训练：数据、注意力布局和蒸馏目标

干净数据为 $x_0,\ldots,x_{L-1}$，老师是冻结基座给出的下一项概率：

```math
p_j=p_\theta(\cdot\mid x_0,\ldots,x_j).                              \tag{11}
```

学生看干净前缀和带噪块，产生 $q_j$。两边相同位置 j 的 logits 都预测 j+1。
训练以老师的整张概率表作为监督。

### 5.1 同一遍前向的干净／带噪两条路径

输入拼成 $[x,z]$，长度为 2L，两边的位置编号重复 0 到 L−1。
定义块起点 $b(j)=B\lfloor j/B\rfloor$，读取规则为：

| 查询 | 可读的干净位置 | 可读的带噪位置 | 适配器 |
| --- | --- | --- | --- |
| 干净 j | $0\le k\le j$ | $\varnothing$ | 关 |
| 带噪 j | $k<b(j)$ | $b(j)\le k\le j$ | 开 |

$\varnothing$ 表示空集合。两边第一项 BOS（序列起始 token）都保持干净、关适配器；学生损失从位置 1 开始计算。
每个样本是一条独立的固定长度序列。老师在最后一行同样给出下一项分布，供该行蒸馏使用。

这使干净分支等于普通 AR 老师；每个学生块等于“先缓存此前的干净块，再单独算当前噪声块”。
测试逐项比较这两种布局的 logits。
[distillation.py](../src/blockspec/distillation.py) 明确构造 mask、位置编号和有效损失行。

### 5.2 四种差异函数

```math
\begin{aligned}
D_{TV}(p,q)&=\tfrac12\sum_v|p_v-q_v|,\\
L_1(p,q)&=\sum_v|p_v-q_v|=2D_{TV}(p,q),\\
D_{KL}(q\Vert p)&=\sum_vq_v\log(q_v/p_v),\\
D_{KL}(p\Vert q)&=\sum_vp_v\log(p_v/q_v).                             \tag{12}
\end{aligned}
```

TV 是总变差距离，描述两张概率表的质量差异；KL 是相对熵，方向由参数顺序决定。
代码区分 `l1`、`tv`、`reverse_kl`（学生到老师）、`forward_kl`（老师到学生）。
原研究的绝对差目标对应 `l1`，其值为 TV 的两倍。

此外，`reverse_kl_l1` 表示 $D_{KL}(q\Vert p)+L_1(p,q)$，共用同一对概率表计算。
它对应[原论文式 (3)](https://arxiv.org/pdf/2609.04010) 的联合热身设置，两个分量的系数都为 1。
热身结束后保留 L1。测试核对联合损失及其梯度，老师分支使用停止梯度。

训练优化样本与随机噪声上的平均差异：

```math
\min_\phi\ \mathbb E_{x,z}
\left[\frac1{L-1}\sum_{j=1}^{L-1}D(p_j,q_{\phi,j})\right],\qquad\theta\text{ 固定}. \tag{13}
```

学生有梯度，老师停止梯度。支持 2、4、6、8 等小块到大块的课程；当前训练默认使用反向 KL＋L1 热身，之后改为 L1。
还可选择纯 KL、前向 KL 热身或单一目标。热身计入总步数，块长按训练进度依次切换。
数据窗口与噪声各用独立随机数生成器。[training.py](../src/blockspec/training.py) 提供课程入口。

训练入口支持固定裁剪、固定噪声的独立验证集，记录给定真实前缀时的 TV、前向 KL 和 argmax 一致率。
训练前检查问题与样本划分；验证以固定权重前向计算，窗口及噪声有独立指纹。

蒸馏默认比较温度 1 的全词表软分布，以便获得梯度。
后文“接受率 = 1−TV”的恒等式使用实际生成时的 p、q。
训练与生成采用相同的概率处理时，训练 TV 直接对应单位置接受率；在贪心或其他温度／截断设置下，它作为可微代理目标。

### 5.3 初始梯度与训练数据的作用

softmax 的导数为 $\partial q_i/\partial l_j=q_i(\mathbf1[i=j]-q_j)$。代入式 (12)：

```math
\frac{\partial D_{KL}(p\Vert q)}{\partial l_j}=q_j-p_j,\qquad
\frac{\partial D_{TV}(p,q)}{\partial l_j}
=\tfrac12q_j\left[s_j-\sum_iq_i s_i\right],\quad s_i=\operatorname{sign}(q_i-p_i). \tag{14}
```

当老师概率 $p_j$ 较大而学生概率 $q_j$ 很小时，TV 梯度受 $q_j$ 缩放，前向 KL 的梯度则约为 $-p_j$。
等号位置 TV 选取合法次梯度。这给出了热身的梯度依据，热身配置通过接受长度和总时间比较。

记 $R=\sum_iq_i\log(q_i/p_i)$，反向 KL 的导数为 $q_j[\log(q_j/p_j)-R]$。
因此联合热身对第 j 个 logit 的导数是
$q_j[\log(q_j/p_j)-R+s_j-\sum_iq_i s_i]$，绝对值项对应 L1。
联合热身同样带 $q_j$ 因子；它与前向 KL 的梯度特性构成两种热身选择。

老师读取块内真实历史，学生读取块内噪声。对固定学生可见信息 c，最小化平均前向 KL 的解为：

```math
q^*(v\mid c)=\mathbb E[p(v\mid\text{老师历史})\mid c].                \tag{15}
```

推导：把平均 KL 写成 $C-\sum_v\bar p_v\log q_v$，其中 C 对 q 的导数为零。
加上约束 $\sum_vq_v=1$ 的乘子 $\lambda$，求导得到 $-\bar p_v/q_v+\lambda=0$，
求和得 $\lambda=1$，所以 $q=\bar p$。同一可见前缀有多种合理后续时，最优学生学习的是这些条件分布的平均。

因此数据决定了“在哪些上下文模仿老师”。离线数据越贴近线上上下文，蒸馏学到的条件分布就越有针对性。

## 6. 一轮两遍的解码对齐

已提交历史 h 长度为 L，最后一项叫种子 s。缓存保存前 L−1 项，s 在本轮计算。
块长 B 包含一个干净根 token 和 B−1 个噪声起草位置：

| 步骤 | 输入 | 输出概率的含义 | 留下的状态 |
| --- | --- | --- | --- |
| 起草 | `[s,z1,…,z(B−1)]` | 第 0 行给根；第 i 行给候选 i | 干净 s 的 KV |
| 验证 | `[y0,y1,…,y(B−1)]` | 第 i−1 行验证 yi；最后一行给全接受时额外 token | 基座真实路径 KV |
| 更新，可选 | 起草输入、原缓存、有效老师 logits | 重算学生梯度 | 下一轮的适配器版本 |

根 $y_0$ 从适配器关的第 0 行抽，因此已经服从目标。后续 $y_i\sim q_i$ 来自带噪位置，
条件于本轮噪声独立抽样。老师读取实际候选路径：
$p_i=p_\theta(\cdot\mid h,y_0,\ldots,y_{i-1})$。

z 是学生输入，y 是从学生输出分布抽出的候选。线上重放保存 z，以恢复相同的学生输入。
[decoding.py](../src/blockspec/decoding.py) 实现这一对齐，并提供逐 token 一次前向的 AR 基线。

## 7. 概率校正如何得到目标分布

候选 $Y\sim q$，再抽独立均匀数 $U\in[0,1)$，按下式接受：

```math
a(Y)=\min\{1,p_Y/q_Y\},\qquad U<a(Y).                               \tag{16}
```

若拒绝，从残差分布抽替代 token：

```math
r_v=\frac{(p_v-q_v)_+}{Z},\qquad Z=\sum_u(p_u-q_u)_+,
\qquad a_+=\max(a,0).                                                \tag{17}
```

这是 [精确投机解码](https://proceedings.mlr.press/v202/leviathan23a.html) 的关键校正。下面重新证明。
直接接受 v 的概率为 $q_va(v)=\min(p_v,q_v)$。因为两张表总和相同，正差与负差总量相同：

```math
\sum_v(p_v-q_v)_+=\sum_v(q_v-p_v)_+
=1-\sum_v\min(p_v,q_v)=D_{TV}(p,q)=Z.                                \tag{18}
```

因此总拒绝概率为 Z，最终输出 v 的概率正好是：

```math
\Pr(\text{输出 }v)=\min(p_v,q_v)+Zr_v
=\min(p_v,q_v)+(p_v-q_v)_+=p_v.                                     \tag{19}
```

例如 $p=(0.2,0.5,0.3)$、$q=(0.6,0.1,0.3)$，直接接受质量是 $(0.2,0.1,0.3)$，
总拒绝质量 0.4，残差分布将这部分质量补给 B，最终就得到 p。

当 $q_v=0$ 时，候选 v 的抽样概率为零；残差分支承担其目标概率质量。
当 p=q 时 Z=0，所有候选直接接受。

### 7.1 多步、EOS 与贪心

按顺序验证，第一处拒绝后发出替代 token 并结束本轮，更深的候选和对应 logits 随本轮丢弃。
全部接受时，从最后一行额外抽一项，此时它的条件正是真实提交的历史。
对第一项应用式 (19)，条件于第一项再对第二项应用，逐项归纳就得到式 (2)。
EOS 与长度预算截取生成序列的一个前缀，该前缀也服从相应的目标边缘分布。

贪心时 p 为 one-hot，错误候选必被换成正确贪心项，故精确算术下与 AR 逐 token 一致。
GPU 批形状和运算顺序带来的浮点舍入，可能交换数值接近的两个 logits；实验同时记录数值误差与贪心一致率。

## 8. 缓存隔离的证明

KV cache 保存每层历史位置的键和值，后续直接读取这些结果。

每轮开始时，缓存满足一致性条件：它等于固定基座、适配器全关计算已提交历史前 L−1 项的结果。
种子 s 的适配器关，读取范围为干净历史和 s 自身。逐层归纳：其嵌入由 s 确定；前层干净表示和缓存由历史与基座确定；
下一层由这些量继续计算。因此种子的所有 KV 都等于在同一历史下单独输入该种子所得的基座结果，可以接入历史缓存；噪声位置的 KV 随本轮释放。

验证时适配器全部关闭，提交首次拒绝之前的合法路径 KV。替代 token 或全接受后的额外 token 成为下一轮种子，
其 KV 留到下一轮计算。这样缓存始终保存至“新历史倒数第二项”，满足下一轮的一致性条件。
全接受、第一处拒绝、部分接受、EOS、短尾都有测试。

证明使用两个条件：基座权重固定，缓存全部来自适配器关闭的计算。任意层的适配器都可以在此条件下继续更新。
默认路径采用函数式缓存和 `torch.cat`；可选 GPU 图路径在内部复用固定工作区，返回独立存储的缓存快照，
见下一节。重放容量由块数配置，实际占用由前缀长度及切片持有的底层存储共同决定。

### 8.1 固定工作区与反馈快照

GPU 图可以记录一段固定形状的运算，后续向同一地址放入新输入，再一次提交这段运算，减少逐个算子的 CPU 调度。
执行器固定地址、形状和控制流，并显式管理参数版本和反馈快照。
这些约束见 [PyTorch 2.11 CUDA 图说明](https://docs.pytorch.org/docs/2.11/notes/cuda.html#cuda-graphs)。
[execution.py](../src/blockspec/execution.py) 在 `Decoder` 外实现这一执行层。

设真实历史有 l 个已缓存位置，新输入有 n 项。选择固定历史容量 P，满足 $P\ge l$。
物理存储为“P 格历史＋n 格本次输入”，历史区域的第 l 到 P−1 格用作填充位。
把原来逻辑上的键索引 j 映射为：

```math
f(j)=\begin{cases}j,&0\le j<l,\\P+j-l,&l\le j<l+n.\end{cases}
```

真实历史与本次输入的 K、V 按 f 放置；这些位置的读取关系与原 mask 相同，填充位的注意力权重设为零。
位置编码使用逻辑位置，例如新输入的第一项位置为 l，物理存储偏移为 P。
令 $a_{ij}$ 为式 (3) 中允许位置的注意力分数，原来给 j 的权重是
$e^{a_{ij}}/\sum_{k\text{ 允许}}e^{a_{ik}}$。填充位对分母的贡献为 $e^{-\infty}=0$，
所以 f(j) 的权重等于原 j 位置的权重，乘上相同的 V 后输出也相同。逐层归纳，得到相同的 logits 和有效 KV。
验证结束再按逆映射提取有效位置，提交合法路径。上述推导使用实数运算，浮点实现通过数值对照检验。

这里还有一个与在线学习直接相关的所有权问题。假设第 t 轮工作区为 A，若反馈保存的是 A 的视图，
第 t+1 轮向 A 写新 KV，就同时改变了旧训练样本。`detach()` 与原张量共享存储。
因此本实现每次返回的有效 KV 经一次独立复制／拼接成为 $S_t$；logits 和边界特征也复制。
下一轮在私有 A 中计算，重放继续持有第 t 轮的 $S_t$，满足 9.3 的输入一致性条件。
`PackedCache` 把各层 KV 放在一个张量中，支持一次整体复制，保持相同的缓存内容与提交规则。
测试复用同一个工作区、缩短历史、修改适配器，再对旧反馈做反向，逐项检查旧快照。

所有短查询形状在请求计时前准备，入口核对查询与形状配置。长 prefill 经同一模型普通执行。
在线更新按“验证、提交、普通反向、AdamW”执行，原地更新低秩矩阵 A、B，下一轮图读取同一地址中的新值。
替换参数存储、修改旋转缓冲区或切换精度后，重新准备执行器。
当前执行配置为单请求、单所有者、同步更新和 FP32 CUDA。

## 9. 在线续训：输入、目标和更新

线上主题、风格、长度可能偏离离线数据。可以用刚完成的验证 logits 继续训练草稿，免去额外教师前向。
用验证反馈训练提议模型的相关工作包括 [Online Speculative Decoding](https://arxiv.org/abs/2310.07177)
和 [Test-Time Speculation](https://arxiv.org/abs/2605.09329)。这里独立实现同步重放，保留全适配器基线，
并提供下文推导的末层子集续训选项。

### 9.1 哪些位置有有效监督

每个反馈保存：干净种子与噪声输入、种子之前的基座 KV、老师 logits。
如果接受 k 个噪声候选，第 k+1 个拒绝，保留前 k+1 行；全部接受则保留全部 B−1 行。
首次拒绝位置的老师历史等于已提交前缀，因此该位置也纳入监督。
EOS 或长度预算结束生成时，监督行按返回前缀截取；生成中的请求按配置触发更新，时点位于本轮提交与下轮起草之间。

### 9.2 全适配器重放与更新

维护最多 R 个反馈块，每 S 轮最多更新一次。反馈集合为 $\mathcal B_t$，$m_{bi}$ 指示有效位置：

```math
L_t(\phi)=\frac{\sum_{b\in\mathcal B_t}\sum_i
 m_{bi}D(p_{bi},q_\phi(\cdot\mid c_b,z_b)_i)}{\sum_{b,i}m_{bi}},
\qquad \phi\leftarrow\operatorname{AdamW}(\phi,\nabla_\phi L_t).       \tag{20}
```

老师停止梯度；保存的反馈组成经验训练集，学生使用当前参数重新前向，建立计算图并反传。
各反馈块依次处理、累积梯度，再执行裁剪和参数更新；激活内存按一个块的规模使用。

默认 R=4、S=16、学习率 $10^{-4}$、L1 损失，继续训练离线检查点中的 A、B。
[online.py](../src/blockspec/online.py) 实现学生前向、backward 和 optimizer step。
同一 learner 的权重和 Adam 状态跨请求保留，请求结束释放反馈和 KV。
检查点保存权重；重建 learner 时初始化 Adam 状态。

### 9.3 末层续训与特征复用

离线训练覆盖所有层的适配器。末层在线方案训练最后 k 层中的原有 A、B，并固定前面层的适配器。
例如 28 层模型取 k=4，继续训练原检查点第 25–28 层的低秩矩阵。
`OnlineConfig(train_last_layers=4)` 开启这个选择；默认的 `None` 对应 9.2 的全适配器续训。

将前段适配器写成 $\phi_{<j}$，可训练后段写成 $\psi=\phi_{\ge j}$。对一个已保存的种子和噪声输入，
前 j 层产生隐藏向量 H，剩余层及词表投影产生 logits $\ell$：

```math
H=F_{<j}(c,z;\theta,\phi_{<j}),\qquad
\ell=G_{\ge j}(H,K^\theta;\psi),\qquad q=\operatorname{softmax}(\ell). \tag{20a}
```

$K^\theta$ 表示后段所需的干净基座历史缓存。H 直接取自本轮起草前向，包含种子和噪声各位置的特征。
位置编号、注意力 mask 和适配器开关一同保存。

为什么可以安全断开 H 的梯度？导数描述“轻微改变参数时，结果如何变化”。对于一组参数，
把每一项这样的导数排成向量就是梯度；矩阵 $\partial G/\partial H$ 收集输出各项对输入各项的导数。
链式法则把“参数直接改变后段”和“参数先改变 H，再经后段影响损失”两条作用相加。
令 $g=\partial L/\partial\ell$，则完整重算给出的梯度是：

```math
\nabla_\psi L
=\left(\frac{\partial G}{\partial\psi}\right)^\top g
+\left(\frac{\partial H}{\partial\psi}\right)^\top
  \left(\frac{\partial G}{\partial H}\right)^\top g
=\left(\frac{\partial G}{\partial\psi}\right)^\top g.                 \tag{20b}
```

最后一步成立，是因为 H 由已冻结的前段产生，$\partial H/\partial\psi=0$。
因此给定相同数据、当前 $\psi$ 和相同损失，复用 H 并重算后段，得到的正是
**相同末层参数子集**在完整重算中应得的梯度。
裁剪对象、Adam 初始状态及超参数也相同时，一步更新相同；逐步归纳得到多次更新相同。
这个选择将适应新分布的任务交给后 k 层，k 决定了可训练范围和计算成本。

这里有三条独立的有效性条件：

- H 对应的前段基座和适配器保持固定，H 可跨后段的多次更新复用。
- 重放历史 KV 来自适配器关闭的基座前向。
- H 的噪声、位置和读取关系与采集反馈时一致。

实现保存后 k 层历史 KV 和分界特征副本，检查前段参数版本与冻结状态。
前段发生修改时重新构造 learner；请求结束释放反馈数据。

验证时完整重算同一前段冻结的模型，比较所有可训练梯度。适配器 A、B 均赋随机权重，三种切分下 logits 和梯度一致，
连续三次 Adam 更新也逐项一致。线性与树解码检查基座／前段权重保持固定、末段参数更新及贪心输出一致性。
接受长度和计算成本通过 13.3 的请求流评测比较。

## 10. 在线参数更新的正确性证明

令 $\mathcal F_t$ 包括第 t 轮开始前的历史、过去反馈、随机数和参数版本。
条件于这些已有信息，本轮参数 $\phi_t$ 已经确定。再固定本轮噪声，就固定了提议概率表 $q_t$。
式 (16)–(19) 对任何这样的 q 都成立。

先用本轮原 q 完成接受／拒绝，再计算 $\phi_{t+1}$；新参数从下一轮开始生效。
对各种可能的过去取平均（全概率公式），本轮输出服从基座条件分布；逐轮归纳得到完整序列结论。
校正负责保持目标分布；学习通过改变 q 影响接受长度和运行成本。

实现按这一顺序同步执行：固定本轮 q，完成验证，提交合法路径的基座 KV，更新适配器，开始下一轮。
基座权重在整个请求流中保持固定。

## 11. 前缀树的构建、验证与在线反馈

线性方案每个位置抽一项。低 batch 时可以增加候选，把前缀按 $\sum_i\log q_i(y_i)$ 排序，
保留有限个前缀，用树注意力一起验证。每个节点读取共同历史、祖先与自身，位置编号按深度设置。

树由 top-k 候选确定性构建，生成时在已验证节点直接从目标 p 抽下一项：
存在对应子节点就继续，走出树时发出该 token 并结束本轮。
对于任何固定树，每一次抽样都服从目标条件分布；树决定一次能复用多少已算好的 logits。
该遍历适用于贪心和随机目标。原文第 4.1.2 节说明 top-k 与前缀预算，附录 B.3 的完整伪代码是线性路径；
固定公开版本的 [`tree_verify_stage`](https://github.com/ifm-ai/uno/blob/ed2ee36bb7a3aea8732ebc635b3f09490a032ea3/nano_vllm_uno/engine/two_pass_decoding.py)
同样先从目标 logits 抽 token，再调用树遍历。

### 11.1 前缀树构建与证明

[tree.py](../src/blockspec/tree.py) 用一个最大优先队列按前缀分数取节点。根计入预算 V，
每次取出最高分可扩展前缀，再把它的至多 k 个孩子加入队列。每项概率都在 [0,1] 中，
所以孩子的概率乘积小于或等于父亲；每个深节点之前都存在分数更高或相等的祖先。
因此优先队列可逐个取出每位置 top-k 范围内的全局最高分前缀，搜索量由预算 V 控制。
测试枚举小树的全部前缀并排序，与队列输出逐一对比。

正温度时，树分数使用按该温度缩放的学生软概率；贪心目标使用温度 1 的软分数构建多分支。
树按学生的全词表软分布评分，再应用候选 top-k 选择节点；目标抽样使用自己的温度与截断设置。

### 11.2 目标路径遍历、缓存压缩与在线反馈

设树节点 n 对应路径 $y_0,\ldots,y_d$。通过树 mask 和按深度的位置编号，其输出分布等于
单独运行该路径的 $p_\theta(\cdot\mid h,y_0,\ldots,y_d)$，这有每个节点的数值对照。
从该分布直接抽下一项：沿对应孩子继续遍历，走出树时发出该 token 并结束本轮；到达叶子后再抽一项作为额外输出。
对固定树反复使用条件概率乘法规则，即证明最终输出服从 AR。走出树的 token 也直接来自 p，完成该轮输出。

验证后收集提交路径的节点索引，把干净历史和这些祖先节点的 KV 按路径顺序 gather；
最后一个输出作为下一轮种子，其 KV 在下一轮计算。
测试逐节点比较压缩缓存和独立路径缓存，并覆盖根节点预算、分支、短尾和 EOS。

在线反馈采用实际遍历节点的老师 logits，按深度匹配原噪声输入的第 1、2、…行。
走出树的位置同样提供有效老师目标，最多与 B−1 个学生位置配对。
同一个 `OnlineLearner` 在树解码后使用这些反馈续训适配器。
树统计中的 `proposed` 是根之外的候选节点总数，`accepted` 是实际匹配的子节点数；
每轮输出长度反映树对目标路径的覆盖程度。

## 12. 在线训练的计算成本

单项 token 通过一个 $d_{in}\to d_{out}$ 线性层，基座前向约有 $2d_{in}d_{out}$ 次浮点运算，
低秩附加前向约有 $2r(d_{in}+d_{out})$ 次。
为更新前面层的适配器，梯度还要穿过后面冻结层，计算输入梯度 $W^\top g$。

在线成本还包括学生重放前向、激活存储、词表投影、概率损失、Adam 状态读写、反馈复制和同步。
`update_seconds` 记录更新区域，净 TPS 由整条生成流程的输出数与耗时计算。

### 12.1 从接受长度到净收益条件

在线性路径中，令 K 为一轮接受的噪声候选数。完整非 EOS 轮产生 $N=2+K$ 个 token，用两遍前向；全接受时 N=B+1。
非负整数的尾和公式给出：

```math
\mathbb E[N]=2+\sum_{i=1}^{B-1}\Pr(K\ge i).                           \tag{21}
```

证明：每个整数 k 都等于 $\sum_i\mathbf1[k\ge i]$，两边取平均即可。
单位置接受率是 $1-D_{TV}(p,q)$。连续 i 项的接受概率由每一步在前面均已接受条件下的接受率相乘得到。
若这些条件接受率都近似为同一个 a，便有 $\Pr(K\ge i)\approx a^i$；实际测量直接统计每轮的 K。

设 AR 每项平均耗时 $C_A$；每轮起草、验证、调度分别为 $C_D,C_V,C_H$；一次更新为 $C_U$，
平均 S 轮更新一次。忽略短尾、假设稳定工作负载：

```math
TPS_{static}\approx\frac{\mathbb E[N]}{C_D+C_V+C_H},\qquad
TPS_{online}\approx\frac{\mathbb E[N_{on}]}{C_D+C_V+C_H+C_U/S}.         \tag{22}
```

在线超过 AR 需要：

```math
\mathbb E[N_{on}]C_A>C_D+C_V+C_H+C_U/S.                               \tag{23}
```

在起草、验证和调度成本相同的条件下，在线版超过静态版还需：

```math
\frac{\mathbb E[N_{on}]}{\mathbb E[N_{static}]}
>1+\frac{C_U/S}{C_D+C_V+C_H}.                                        \tag{24}
```

式 (24) 给出了学习成本所需的接受长度增幅。测量时将 prefill、EOS 短尾和学习过程一并计入，
预热后交换方法的执行顺序，并重复运行以观察 GPU 负载引起的波动。

### 12.2 末层特征重放节省了哪一部分

全量重放的 $C_U$ 包括所有层的学生前向与必要输入反向。9.3 的方法重算后 k 层，为这些层的适配器维护梯度与 Adam。
它的计算包含后段前向／反向、完整词表投影和损失。起草、验证与 AR 基线使用同一个完整基座。

如果新增特征保存和检查的平均每轮成本为 $C_F$，式 (22) 的在线分母相应成为
$C_D+C_V+C_H+C_F+C_{U,k}/S$。k 同时影响更新耗时和可学习的参数范围，选择时比较净 TPS 与接受长度。
28 层 r=32 示例中，全适配器为 27,983,872 项，最后 4 层为 3,997,696 项，即全量参数的 1/7。
更新耗时由这些参数对应的计算量、词表投影和状态读写共同决定。
B=4、隐藏维度 1536、FP32 时，一份 H 为 $4\times1536\times4=24,576$ 字节；
完整反馈还包含后段 KV、位置、mask 和老师词表 logits。

### 12.3 图准备与流级吞吐

把每次请求的 prefill、生成、反馈复制和学习合计为请求流耗时 T，输出数为 N，
一次性图准备为 F、learner 初始化为 I，可以分别计算：

```math
TPS_{请求流}=\frac{N}{T},\qquad TPS_{含准备}=\frac{N}{T+F+I}.
```

含准备的加速比使用两种方法各自的 $N/(T+F+I)$ 相除。
三路评测分别按各方法单独部署所需的图形状计入 F，其中包括 AR 使用的短 prefill 形状。
若两种方法的每项成本近似为 $c_A,c_S$，流级净加速的条件为：

```math
N(c_A-c_S)>F_S+I_S-F_A-I_A.
```

左边是 N 项输出累计节省的时间，右边是额外准备时间；请求流越长，准备费用分摊到每项后的数值越小。
固定容量图还会处理被 mask 的注意力位置，并占用相应存储。容量选择因此同时考虑历史长度、执行时间和显存。

### 13.1 低精度差异的逐层定位

`audit_model_precision.py` 在同一基座上比较普通／配对前向，将逐层差异输出到终端，并在完成后恢复 hook 和全局精度开关。
32 个随机词表 token 的受控探针中，第一处差异已经出现在首层 Q 投影，早于注意力；
输入 RMSNorm 则相同。关闭 BF16 的低精度中间归约后，首层最大差异由 0.0625 降为 0.00390625，
后续层继续传播和放大这部分差异。
这种批运算与切片运算的舍入差异符合 [PyTorch 2.11 的数值说明](https://docs.pytorch.org/docs/2.11/notes/numerical_accuracy.html)。

逐步误差还可以通过耦合推导到整条序列：若第 t 步在每个共同历史上的目标核 TV 误差至多为 $\epsilon_t$，
最大耦合使该步输出相同的概率至少为 $1-\epsilon_t$。连续各步均相同的概率至少为这些数值的乘积，
于是序列分布的 TV 距离至多为 $1-\prod_t(1-\epsilon_t)\le\sum_t\epsilon_t$。
该式将每步目标分布的误差上界与整条序列的误差联系起来。当前吞吐基准采用 FP32。

### 13.2 适配器的离线训练

真实基座上从随机 r=32 全适配器开始，600 步、每步 2×128 token，总计 153,600 个训练 token；
前 150 步使用反向 KL＋L1，之后纯 L1，块长按 2→4 推进、各占 300 步，学习率 $3\times10^{-4}$，全程 FP32。
适配器有 27,983,872 个参数，训练连同固定验证耗时 134.91 秒，训练前后基座指纹相同。
联合热身目标的公式与梯度见 5.2。

| 固定验证指标 | B=2：训练前→后 | B=4：训练前→后 |
| --- | --- | --- |
| TV 距离（越小越好） | 0.9281 → 0.6004 | 0.9387 → 0.7082 |
| 最大概率项一致率 | 4.63% → 36.71% | 3.74% → 24.02% |

每个块长使用同一组 1,016 个有效位置，窗口和噪声固定。
训练 72 条、验证 17 条按问题分开，另有 23 条保留测试。验证以固定权重前向计算。
表中指标描述给定数据前缀时的老师／学生概率差异；自由生成时的接受长度与 TPS 在下一节测量。
训练后的两种块长均表现为 TV 降低、最大概率项一致率提高。
当前检查点及数据来源清单存放在仓库外，配置、数据 SHA、实现指纹随检查点保存。

### 13.3 三路吞吐与更新成本

## 14. 实验设计与持续更新

当前离线训练数据来自 [OpenThoughts3-1.2M 官方数据集](https://huggingface.co/datasets/open-thoughts/OpenThoughts3-1.2M)
的子集。该数据集同一问题有多份回答，因此按规范化问题 hash 分组，使同一问题的回答归入同一划分。
当前 112 条记录含 111 个问题，分为训练 72、验证 17、保留测试 23；含代码 24、数学 80、科学 8 条。
训练集用于适配器学习，验证集用于配置选择与工程评测，保留测试用于设计确定后的最终评测。

准备入口读取预定页面，按基座本地聊天模板编码，保存 token、来源行号、问题／文本 hash 和各文件 hash；
采集时选择完整单元格，并记录观察到的仓库 revision 与实际响应 hash，形成可核验的来源清单。
数据和 manifest 位于仓库外，数据准备实现保存在仓库内。

后续实验围绕四个问题展开：

1. 历史长度：扩大完整基座与外部参照的长历史数值对照，测量图容量对时间和显存的影响。
2. 离线学习：扩展训练记录和训练步数，联合观察固定前缀 TV、自由生成接受长度及净 TPS。
3. 推理执行：优化 KV 读写与投影调用，在 AR、静态和在线三路中共享适用的执行优化。
4. 在线适应：按主题组织连续请求流，比较更新频率、重放长度和可训练层数，记录累计输出数、累计耗时和接受长度轨迹。

所有方法固定精度、采样设置、提示、预算和 KV 条件，预热后正反顺序成对运行。
随机采样比较统计分布，贪心生成逐项比较输出。配置通过验证集选择，最终在保留测试上评测。
主报告随设计和实验同步更新，集中保留当前原理、配置、数据、结论和运行入口；版本演变由 Git 记录。
