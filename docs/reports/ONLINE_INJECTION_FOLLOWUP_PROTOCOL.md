# 去除 effort 提示后的思考预算与注入格式对照

本轮针对首轮的“资料后立即结束 thinking”现象，比较资料内容、插入时机和外层包装。继续采用单轨迹自回归采样，不混入 IS/MH 或候选选择。首轮的 312 份结果及其冻结文件保持独立。

## 预定矩阵

复用首轮全部 8 道 TechQA DEV 问题和全部 28,481 份文档。BM25 仅按原问题检索一次、固定 top-2，使同题所有预算、位置和内容条件使用相同来源；不使用 gold 决定资料或时机。本轮专门隔离注入机制，不测试 query 随推理更新的收益。

思考预算为 256、1,024、4,096 token。最终回答另有独立 512-token 上限；较早结束思考不能获得额外回答预算。温度 1、完整支持分布、BF16、上下文 8,192，所有正式计算使用用户选定的 198 物理 3 号单卡。

每档预算有以下 14 个方法，共 8 × 3 × 14 = 336 份回答：

| 方法组 | 内容条件 | 条数 |
|---|---|---:|
| 闭卷 | 无资料 | 1 |
| 静态 RAG，资料在 user 消息内 | 相关、同长度无关正文 | 2 |
| assistant thinking 起点追加 | 相关、同长度无关正文 | 2 |
| 第 32 个生成 token 后追加 | 相关、同长度无关正文 | 2 |
| 第 32 token 追加，去除外层指令包装 | 相关、同长度无关正文 | 2 |
| 第 32 token 追加，仅包装与来源标签 | 正文替换为等 token 数换行 | 1 |
| SC 下降触发追加 | 相关、同长度无关正文 | 2 |
| 文本规则触发追加 | 相关、同长度无关正文 | 2 |

动态时机每 32 token 检查一次，最早 64 token；SC 使用当前 32-token 均值较最初窗口下降 5% 的原阈值，规则沿用既有版本/不确定性等正则。模型提前结束或信号未触发时保留无注入结果，不强行补一次。所有方法使用相同的请求切分，避免首轮句界模式中单 token 等待造成的额外随机流差异。

## prompt 与 token 对齐

不调用会按预算映射 effort 的 `resolve_thinking`。在当前固定 tokenizer 中，省略 effort 参数会加入 xhigh 指令；本轮明确选用其不输出 effort 文本的 `medium` 模板分支。生成前保存实际 prompt，并断言完全不含 `Reasoning effort is set to`，且 thinking 已打开。三档预算共用相同 prompt token IDs，预算仅由控制器计数限制。

无关材料为人工编写的庭院、房间和自然景物描述，不含技术问答答案。对照保留原来源标签和标题，仅替换正文，各文档正文使用相同数量的 tokenizer token。因此它测量正文内容贡献，不能声称已移除标题中的全部领域信息。日志明确标记替换条件，替换内容不冒充来源的真实正文。

去包装条件将外层 `[External reference…]` 与末尾 `Continue reasoning…` 替换为相同 token 数的换行，保留文档标签和正文。仅包装条件则保留包装和标签，将正文换为等长度换行。这些对照隔离的是当前外层文本和正文，不代表覆盖所有可能的注入格式；大量换行也可能影响续写行为。

相关、无关、仅包装及去包装资料的总 token 数严格相同，最大 1,024。静态 RAG 直接将相同资料 token IDs 插入 user 结束标记前，避免 decode/re-encode 使条件长度不同。外部资料不能包含 thinking 或聊天结束 token。

## 指标与核对

主要机制指标是资料后的第一个模型 token 是否为 thinking 结束标记、资料后思考 token 数、自然结束/预算强制结束比例、动态触发时机及覆盖率。空回答、答案预算耗尽、EOS 和其他停止原因全部保留。TechQA 回答 F1/EM 单独报告，不把词项重叠当作语义正确率。

每题首先运行闭卷，其他方法轮换次序；每个方法开始前清空 APC，方法内保留 continuation 缓存。起点和中途方法的实际生成前缀与该题闭卷逐 token 核对；相关/无关动态方法也核对注入偏移。若出现前缀不一致，结果保留并标记，不换种子重试；这种样本不作为严格同前缀的机制证据。

所有条件均请求相同的 SC 统计，外部资料及控制标记不参与生成置信度。记录原始 token、概率、资料正文条件、包装条件、触发信号、实际插入位置、耗时、APC 与原生执行图计算估算。主要耗时包含完整前缀生成和续写；索引/资料准备、模型加载、编译和离线判题另记。已知原生图可比逻辑位置多一个自然结束位置，不要求两者无条件严格相等。

统计以同一预算下的问题配对，预算重复不能当成独立新题扩大样本量。保留全部结果与小样本限制，不根据此轮结果调整阈值、资料或预算。完成后导出完整轨迹和对照图，再判断提前结束更支持内容收益、外层格式效应还是一般上下文扰动。

## 冻结与运行

新结果使用独立 deployment/results 目录。运行前冻结源码提交、配置、问题/语料/无关文本 SHA256、实际 prompt、五种资料变体和运行时版本。准备阶段先做纯 CPU token 对齐和模板检查，零正式测量时修复的接口问题单独保留。正式队列结束后停止本次容器释放 3 号卡。
