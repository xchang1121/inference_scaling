# IS 加速研究总结

统计范围：2026年10月18日目标启动至2026年10月28日。代码截止 `35a399f`，比较基线为目标启动前的 `bf0b841`。
早期包括 RTX 3090 上的 Qwen3-1.7B；迁移后使用昇腾 910B3、Qwen3-8B BF16，分别测单卡和双卡张量并行（TP2）。两种平台的结果分别解释。

## 主要结论

1. **固定前缀 IS 的主要实测收益来自减少探索工作。** 两阶段探索、完整补全复用和提前选择已经合入。修正概率接口后的两题对照中，启用 `two_stage + selection_ready` 相对原始固定流程省时72%—85%，实际生成量减少62%—81%。这组结果包含有限预算和提前选择分布的变化。
2. **固定工作量下最明确的执行收益来自完整候选池的跨轮流水线。** 单卡省时17.17%，TP2省时17.59%；请求长度、接受决定、生成 token 和前向量逐项配平。它属于可选的完整候选池 MH 分支，适用于至少两轮后缀更新。
3. **分层、排除原轨迹和按候选块选择提供了有限模型中的分布误差改善。** 已实现并通过单卡、TP2功能检查，保留为可选算法；真实任务准确率尚无充分证据。
4. **跨题并发改善整组完成时间，但单题延迟可能增大。** 这是既有并发能力的验证，单独按吞吐效果评价。
5. **引擎微优化尚未产生已合入的稳定整题加速。** 采样、矩阵布局、执行图、通信、元数据和共享前缀等方向均有检查；部分局部收益在完整模型中只剩约0%—2%，或存在明显回退。

“多数参数下稳定缩短单题 IS 耗时，并减轻长尾影响”的总目标尚未完成。现有证据支持上述具体范围，尚不支持普适加速或准确率提升结论。

## 证据范围

| 对照类型 | 计量对象 | 可以支持的结论 |
| --- | --- | --- |
| 固定工作量模型执行 | 相同请求长度、逻辑决定、实际生成量和前向量 | 执行调度的时延收益；执行形状导致的浮点差异另列 |
| 自然生成的完整入口 | 真实奖励、自然停止及最终内容生成 | 实际成本折中；不同候选和生成长度的影响包含在内 |
| CPU 精确分布或模拟 | 到已知目标的总变差距离 TV、生成 token、理想并行步数 | 有限模型中的统计效率及反例 |
| 算子或计算段测量 | 局部耗时、数值误差、内存与图执行能力 | 局部适用性，需另做完整模型验证 |

TV 越小表示输出分布越接近指定目标。多数 CPU 同预算比较通过运行前随机选择相邻整数轮数配平**期望生成 token 数**，属于期望预算对照。设备 FLOPs 采用 `2 × 参数量 × 实际前向位置数` 的稠密估算，填充位置单列；该估算忽略 attention 随上下文增长的额外项。

长尾指标主要采用“搜索阶段恰有一条请求在途的累计时间”。它描述低并发等待区间；设备仍可能在计算，最长轨迹本身也可能继续增长。

2026年10月28日发现并修复 Ascend 返回温度处理前概率的问题。新累计对照、流水线和近期统计改进均按修复后的概率验证。修复前分组保留为历史证据，其百分比不并入当前累计收益。

### 跨题并发

两题各两个种子，共四个任务，比较现有 `workers=1` 与 `workers=2`。其余模型、M=4、B=256及快速IS设置相同。

| K | 单卡整组耗时下降 | TP2整组耗时下降 |
| ---: | ---: | ---: |
| 1 | 44.70% | 41.97% |
| 2 | 42.42% | 31.79% |
| 4 | 12.77% | 7.56% |

候选轨迹与实际生成量随并发变化。K=4平均单题服务时间在单卡由41.88增至55.91秒、TP2由31.02增至48.24秒；TP2两个长题运行还耗尽4096 token并触发奖励回退。因此该结果支持跨题吞吐改善，尚不支持单题长尾改善或固定并发2作为通用默认值。

### 文献和实现调研

调研覆盖异步rollout、部分rollout恢复、尾部隔离、抢占、动态路由与测试时预算等路线，包括AReaL、SAO、TailSieve、APRIL、FastServe、ConServe、DORA、TAPER、ATTS、PreSTO、CANVAS、UniBoost，以及相关采样、SIR修正和Anytime Monte Carlo。
这些工作有的只做了适用性核对，有的形成上表中的私有原型。训练版本复用、多副本吞吐、额外打分器及投机模型的结论按原应用范围使用，未将论文报告的加速率计为本项目实测收益。

## 历史清理和当前保留范围

早期 `bf0b841` 之后的45条试验提交已按要求撤销并重建，动态B/M/K控制器、首轮K截断、逐轮参数计划、旧首池修正、IS内顺序MH及重复调参记录已从当前实现移除。
后续新实现按独立验证重新合入。当前保留22条提交；失败探针、原始日志、运行快照和CPU数据位于仓外审计目录，正式入口未增加这些临时脚本。

现有成果可分为三类：

- **用于当前IS的成本折中**：完整补全复用、两阶段探索及可选提前选择。
- **用于完整候选池的执行或统计改进**：跨轮流水线、分层、排除原轨迹、按块选择。
- **确保结果可用的修复**：采样概率、取消清理、执行成本和跨轮统计生命周期。

普适引擎提速、更大样本的真实质量收益、同预算下相对固定IS的一般优势仍未得到验证。
