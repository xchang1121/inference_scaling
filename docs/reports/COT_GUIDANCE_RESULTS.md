# 短证据直接插入 CoT：BoN 与 IS 完整实验结果

本轮最高的动态注入结果是 **Block-Metropolized IS + Self-Certainty，F1 15.69**。
静态短证据在所有同算法比较中都更高：主对照最高为静态 + Block-Metropolized
Consilience（17.78）；预先声明的 BoN 候选池前缀比较中，静态 + BoN-4 平均
logprob 达到 18.03。当前结果支持优先使用静态短证据；如果必须中途插入，
优先保留 Block-Metropolized SC 作为下一轮基线。

## 主要对照

16 道新 TechQA DEV 题 × 2 个种子；11 道题提取到了证据，另外 5 道也保留在
整体统计中。F1 为与参考答案的词级重合分数，范围 0–100。下面均为相关证据组。

| 算法 | 静态短证据 F1 | CoT 中途插入 F1 |
|---|---:|---:|
| 单候选 | 17.325 | 13.874 |
| BoN-8 Self-Certainty | 17.011 | 13.521 |
| BoN-8 Consilience | 17.101 | 13.418 |
| BoN-8 平均 logprob | 17.462 | 13.994 |
| SIR-SC | 16.875 | 15.385 |
| Metropolized-SC | 16.891 | 15.601 |
| Block-Metropolized-SC | 16.976 | **15.686** |
| Block-Metropolized-Consilience | **17.779** | 15.042 |

动态 Block-SC 比动态单候选高 1.811 分，比动态 BoN-8 SC 高 2.165 分。
不过，静态单候选的 17.325 仍高于本轮所有动态方法。
这些是本轮观察到的排序：例如动态 Block-SC 相对动态 BoN-8 SC 的按题配对
bootstrap 95% 区间为 [-0.060, 4.859]，尚不足以确定该排序在更大样本上稳定成立。
同算法 Block-SC 的动态−静态差为 -1.290，区间 [-3.504, 0.758]；
BoN-8 三种评分器的动态−静态差分别为 -3.490、-3.683、-3.467，区间均低于零。
这些区间未经多重比较校正。

仅看有证据的 11 道题，动态 Block-SC 为 17.803、静态 Block-Consilience
为 20.438、静态单候选为 20.668；结论没有因排除无证据题而反转。

## 更多候选没有稳定改善 F1

以下是同一个 BoN-8 池的前 N 条候选，评分器不使用标准答案；不是新增的独立
生成实验，也不是用 F1 做候选选择。

| N | 动态 SC | 动态 Consilience | 动态平均 logprob | 静态平均 logprob |
|---|---:|---:|---:|---:|
| 2 | 14.071 | 14.566 | 14.335 | 17.293 |
| 3 | 14.549 | 14.379 | 14.423 | 17.850 |
| 4 | 14.551 | 13.908 | 14.602 | **18.027** |
| 8 | 13.521 | 13.418 | 13.994 | 17.462 |

动态 Block-SC 平均搜索消耗 1,368 token；动态 BoN-4 约 1,447，BoN-8 约
3,002。Block-SC 的较高 F1 不是靠比 BoN-8 消耗更多搜索 token 得到的。
所有组使用相同的 65,536 搜索 token 上限，但实际计算量不同，不能称为严格等
FLOPs。最终答案与证据提取的成本另外记录。

## 提前收尾与无关文本对照

每种评分器共有 22 次实际可插入证据的题目/种子组合。

| 动态方法 | 相关证据后立即结束思考 | 等长无关文本后立即结束思考 |
|---|---:|---:|
| 单候选 | 5/22 | 8/22 |
| BoN-8 SC | 16/22 | 17/22 |
| BoN-8 Consilience | 5/22 | 4/22 |
| Block-SC | 15/22 | 19/22 |
| Block-Consilience | 6/22 | 9/22 |

SC 更常选中立即收尾的候选；无关文本也出现该现象，因此“立即收尾”不能作为
有效吸收证据的指标。Consilience 让更多候选继续思考，但没有带来最高 F1。
这里的无关对照只替换证据正文，保留相同 token 长度、来源标签和外层格式；
它不能单独证明究竟是格式还是插入时机导致收尾。

证据内容仍然有用：动态 Block-SC 的相关/无关 F1 是 15.686/11.215，
差 +4.471，配对区间 [1.829, 7.719]；静态 Block-Consilience 是
17.779/11.266，差 +6.513。当前短证据直插 CoT 有内容收益，但没有超过静态放置。

## 长度、完整性与复核

- 上下文 32,768 token，思考上限 8,192，最终回答上限 16,384；回答分块续写到自然 EOS。
- 最长最终回答 1,618 token；最长保留候选思考 2,466 token。最终回答截断为 **0**，选中轨迹强制结束思考为 **0**。
- 640 个逻辑搜索条件；完全相同且无证据的请求复用后为 490 个实际搜索单元。
- 1,176 个实际候选答案中，9 个为空；1,024 个最终选择视图中，1 个为空，位于无关文本的动态 BoN-logprob 组。空回答未删除或重采样。
- 2,487 次实际搜索生成调用中，22 次含思考阶段 EOS；924 次注入后根节点调用中，4 次立即 EOS、428 次立即输出思考结束标记。调用次数与最终选中答案次数不是同一分母。
- 43,588 项正式审计全部通过；从原始 token/概率/本地 gold 离线重建的 12 份正式及 smoke 文件逐字节一致。
- 两个任务容器均已停止；各运行约 5.31 和 4.54 小时。

两组都在同一“完整句子/段落边界”策略后分叉候选。静态组在生成该前缀时已经
看到证据，动态组在保留该前缀后才获得同一短证据包；没有清空历史、折叠记忆或
自适应检索触发。这是共享前缀后的 BoN/IS 比较，不是独立采样整条思考轨迹的 BoN。
