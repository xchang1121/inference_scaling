# 去除 effort 提示后的预算、位置与注入格式对照

本轮在同 8 道 TechQA、同一份 28,481 文档语料上完成 3 档思考上限 × 14 条件，共 336 条正式轨迹。结果支持当前外层包装与插入位置影响结束行为；没有得到中途注入在质量上稳健优于静态 RAG 的证据。

全部正式模型计算使用 198 物理 3 号单卡，Qwen3.8-27B、BF16、温度 1、单轨迹采样，未使用 IS/MH 或候选选择。生成源码冻结为 `0bc7220744af3147928e1fb74317888a4dc92a1b`。生成退出码 0，无正式失败重试，本次容器已停止。

## 实际控制条件

实际 prompt 不含 low、xhigh 或其他 effort 指令，且 thinking 已打开。当前 tokenizer 省略 effort 会加入 xhigh 文本，因此选择其不输出 effort 文本的 medium 模板分支，并逐题核对实际 token。上限仅由控制器限制，未调用按预算映射 effort 的逻辑。

thinking 上限为 256、1024、4096；回答独立限 512 token。资料最多 1024 token，不扣 thinking 上限，但计入上下文和 prefill 成本。Q209 的 1024 档固定注入实际用了 826 个资料 token 和 581 个思考 token。

各题 BM25 top-2 资料固定，不使用 gold 决定资料或触发。无关对照只替换正文，保留标题与来源标签。去外层包装和仅包装条件使用等 token 数换行，五种资料变体逐题长度相同；静态 RAG 插入相同原始资料 IDs。

## 关键发现

三档的原包装无关正文在第 32 token 插入后均为 8/8 立即输出 `</think>`，相关正文为 6/8，静态相关和无关条件均为 0/8。仅保留包装与来源标签也有 5/8 立即结束。去外层包装的相关组为 0/8 立即 `</think>`，却有 6/8 在 thinking 内直接 EOS，留下空回答。

4096 档所有条件均没有预算强制结束，最大上下文为 2955/8192；资料本身不包含 EOS 或 `</think>`。因此，上述边界行为不依赖低 effort 提示、思考预算耗尽或直接注入结束 token。去掉包装尚不是有效修复，结论也不能扩展到所有可能格式。

| thinking 上限 | 闭卷 F1 | 静态相关 RAG | 第 32 token 相关注入 | SC 动态相关注入 |
|---|---:|---:|---:|---:|
| 256 | 12.8% | 18.5% | 17.3% | 20.1% |
| 1024 | 12.8% | 20.1% | 18.1% | 21.3% |
| 4096 | 12.8% | 20.3% | 18.1% | 21.3% |

4096 档固定注入相对静态 RAG 的 F1 差为 −2.25 个百分点，题级 95% 配对区间 [−6.84, +1.91]；SC 动态为 +0.93，区间 [−4.98, +8.51]。三档中这两种方法的差区间均包含 0，不能宣布优于静态 RAG，也没有证明固定注入不劣。

4096 档平均耗时：静态 53.71 秒、固定注入 24.30 秒、SC 动态 49.40 秒；相对闭卷的原生图计算量估算为 1.207、0.645、1.062 倍。固定注入包含 1/8 空答案，明显更短的 thinking 不能单独证明有效推理加速。256 档固定注入的计算量仍为闭卷的 1.720 倍，说明更短输出与更少计算并不等价。

SC 仅在 7/8 题触发，位置为 64 或 96；规则只在 3/8 题触发，位置为 64 或 128。Q184 思考 970 token 仍没有触发。未触发样本计入整体结果，本轮没有测试新子问题查询的收益。

## 核对与解释边界

336 条原始前缀、资料 ID/长度、SC 与 log probability 重算、回答预算及成本完整性全部通过。全部已核对的注入前闭卷前缀匹配。跨预算 336 对有 10 对生成分歧，3 对涉及 thinking，均来自 Q239 的静态无关条件；其余首次分歧在回答段。同种子不保证逐 token 复现，首轮缓存续写失败仍保留，不能宣称已解决。

同八题的预算重复不构成 24 道独立新题；每条件仅一个种子，F1 是词项重叠，配对区间未校正多重比较。无关对照保留标题，换行控制也可能影响输出。相较首轮还改变了独立回答上限及统一 SC 统计采集，因此跨轮变化不解释为 low 的单因素效应。
